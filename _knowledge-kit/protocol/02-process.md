# ПРОЦЕСС АНАЛИЗА — КАК МЫ РАБОТАЕМ (методология)
> Свод по итогам сессии 4 (разбор Instagram). Читать вместе с `00-protocol/01-rules.md` и шапкой `02-notes/instagram.md`.
> Цель файла: чтобы дальше работать сразу правильно и не повторять ошибок, которые мы прошли.

## 1. Цель проекта
Предельно подробный психологический и биографический портрет Василия по его архиву (переписки, дневники, соцсети, тесты, конспекты психолога). Источник правды — дословный захват из источников + аналитика поверх.

## 2. Каналы чтения (как физически достать текст из файла)
| Тип файла | Как читать |
|---|---|
| Текст (`.docx`, `.csv`, txt-слой) | Кодом: `zipfile`/прямое чтение. 100% точность. |
| Картиночный PDF (Инста, VK, дневник, Приятное, брат) | **render (PyMuPDF, dpi=150) → OCR (`tesseract -l rus+eng --psm 4`) для текста + `view` для визуала.** |

- 🔑 **Апдейт сессии 4:** `view` по картинке в этой среде **РАБОТАЕТ**; OCR даёт текст детерминированно и является основным каналом по подписям. Прежний «закон каналов» (только прямое вложение PDF, view мёртв) — **устарел**. Проверять эмпирически в начале каждой сессии.
- Пайплайн батча: рендер страниц → `tesseract` в один txt → сборка заметок. Слайсы длинных страниц — только если мелкий текст не читается.
- Русский язык OCR обязателен (`tesseract-ocr-rus`), иначе кириллица гарблится.

## 3. ГЛАВНЫЙ ФОРМАТ ЗАМЕТОК — 3 СЛОЯ
- **0a · ЗАХВАТ** (фундамент): запись НА КАЖДУЮ единицу (пост/запись) отдельно, пачки НЕ сворачивать. Все поля дословно: тип, кадр(ы), музыка, подпись целиком, дата, свой/чужой, просмотры, лайки, КАЖДЫЙ комментарий (ник+текст). Нет данных → `[НЕ РАСПОЗНАНО]`/`[НЕ ВИДНО]`. **Не выдумывать ни строки.**
- **0b · INTELLIGENCE** (отдельный слой): реестр людей (кто/частота/роль), тематические нити, таймлайн/арка, флаги значимости, гипотезы, противоречия, перекрёстные ссылки между единицами. Всё со ссылкой на источник.
- **0c · CROSS-FILE**: гипотеза из файла N живёт дальше — при разборе N+n подтверждать/опровергать/уточнять со ссылкой. Единый реестр гипотез → `01-registry/facts-and-hypotheses.md` (статус: открыта / подтверждена файлом… / опровергнута файлом…).
- ⚠️ **Трактовка НИКОГДА не в теле захвата.** Только отдельным слоем или полем «Прим.» (факт-пометка, напр. «цитата из аниме»).

## 4. Уровни анализа (глубина)
1. **Единица** (пост/запись) → дословный захват 0a.
2. **Файл** → синтез 0b (арка, реестр, темы, флаги).
3. **Кросс-файл** → связи и гипотезы через весь архив 0c.
4. **Портрет** → итоговая сборка из всех файлов.

## 5. ОШИБКИ И НЕДОПОНИМАНИЯ (что было не так → как правильно)
1. **Преждевременное `[НЕЧИТАЕМО]`** — пометил читаемые страницы нечитаемыми (перестраховка на `view`). → **Правильно:** не объявлять «невозможно», не перепробовав ВСЁ (OCR, инверсия тёмной темы, слайсы, другое качество). Читать то, что реально есть.
2. **Ложный вывод «половина уйдёт в дыры, не потянуть»** → **Правильно:** OCR решил задачу. Сначала исчерпать методы, потом выводы. (Правило №3: не говори «не могу», не перепробовав всё.)
3. **Сползание в тезисы/пересказ, свёрнутые пачки** → **Правильно:** per-post, всё дословно. Это был бы «самый тяжёлый брак» — выглядит как работа, но не она.
4. **Смешение ярлыков трактовки (`[AoT]`/`[ЛИЧНОЕ]`) с дословным захватом** → **Правильно:** трактовка — отдельный слой/поле «Прим.», захват чистый.
5. **Mojibake в именах при распаковке zip** (Cyrillic без UTF-8 флага → cp437 мусор; плюс дубли-папки от `mkdir`) → **Правильно:** чинить кодировку (`name.encode('cp437').decode('utf-8')`), не плодить дубли, проверять имена перед отдачей. Архив отдавать с UTF-8 флагом.
6. **Недопонимание «подробные/связные»** → **Уточнено** обратной связью: именно 3 слоя (захват + intelligence + cross-file), макс глубина.

- Пользователь кидает файл → **Claude САМ смотрит и делает ПО МАКСИМУМУ ВСЕ слои** (0a захват текст+визуал · 0b intelligence · 0c cross-file · синтез). Без напоминаний, без «по-быстрому», без подмены дешёвым режимом.
- **Claude сам показывает ПРОМЕЖУТОЧНЫЕ ОТЧЁТЫ** по батчам: что сделано, охват X/Y, находки, что осталось.
- **Стандарт по умолчанию = МАКСИМУМ.** Пользователь не должен это напоминать или проверять.
- Любой недобор — **сообщать сразу**, не дожидаясь вопроса.
