# 🧠 KNOWLEDGE-КИТ — тонкий «мозг» проекта self-map

**Это не вся репа. Это её рабочее ядро для загрузки в Project knowledge.**

Полная репа `self-map` весит ~33 МБ и в knowledge не влезает (сырьё дневников и анкет — 90% веса).
Поэтому в knowledge кладётся **только этот кит** — правила, реестр, состояние и протокол текущего
источника. Всё остальное («тело» проекта: сырьё, дословные заметки закрытых источников,
готовые портреты, история инцидентов) живёт в гите `vevdokimovm/self-map` и подтягивается точечно,
когда действительно нужно.

---

## Как этим пользоваться в новом чате

Новый чат для анализа получает три вещи:
1. **Этот кит** — уже в knowledge (правила + реестр + состояние).
2. **PDF источника** — прямым вложением в первое сообщение (сканы читаются только так, не через `view`;
   почему — `infra/vision-channel_investigation.md`).
3. **Промпт вахты** — `ПРОМПТ_вахты.md`, копипастой.

Формат работы, режим чтения, разметку неуверенности, как строить батч, куда писать — чат берёт
**отсюда**, из `protocol/` и `registry/`. Ему не нужно ничего «помнить»: он читает.

## Правила самого кита

- **Кит — это КОПИИ, не оригиналы.** Единственный источник правды — канонические пути в репе
  (`10-life-history/01-registry/…`, `00-infrastructure/…` и т.д.).
- **Кит не редактируется руками.** Правишь оригинал → прогоняешь `build-kit.sh` → кит пересобран.
  Это исключает расхождение кита и канона (никакого merge двух версий).
- **Обновление knowledge:** после релиза, в котором менялись ядровые файлы, пересобери кит и
  обнови его в knowledge (тот же гит-пикер, только папка `_knowledge-kit`).
- **Что НЕ попадает в кит принципиально:** сырьё (`06-diaries`, `08-feedback`, PDF-исходники),
  дословные заметки закрытых источников (`notion-diary.md`, `mentor-part-*.md`,
  `psychologist-sessions.md` — их находки уже сведены в реестр), готовые DOCX-портреты
  (`04-deliverables`). Нужно сырьё для нового чтения — подаётся прямым вложением; нужна история —
  берётся из гита.

## Как загрузить в knowledge

В гит-пикере «Add content from GitHub» выбери **только папку `_knowledge-kit`**, сними галочки
со всех остальных. Вес кита — доли процента лимита вместо 708%.
