> Тип: **консолидация двух линий** (`00-infrastructure/22-merge-protocol.md`). Линия A —
> обжитая репа `self-map`. Линия B — инфраструктура проекта архивного анализа, наработанная
> в шести сессиях Claude и жившая в zip (`INFRA_v19_session5_FINAL` → батчи 14–17 сессии 6).
> Принцип соблюдён: **консолидация, не переписывание.** Ничего не удалено.

## Что откуда взято и почему

| Измерение | Победитель | Довод |
|---|---|---|

## Разрешение конфликтов

1. **Два журнала.** В репе уже лежал `00-infrastructure/watchlog.md` — но это **журнал base-repo**
   (унаследованная копия кита, заголовок «base-repo — Вахтенный журнал»), а не журнал self-map.
   Не тронут. Журнал самой репы заведён в корне: `WATCHLOG.md`. Регистр имени различается
   умышленно — на macOS файловая система нечувствительна к регистру, коллизия исключена
   разными папками.
2. **Датасет дневника.** Рабочий файл проекта и `06-diaries/notion-reflections/datasets/diary-combined.csv`
   **совпали байт-в-байт** (md5 `538ccc78…`, 379 строк / 261 с текстом). Дубль не заводился —
   канал чтения переведён на путь в репе.
3. **`.docx` в репу не кладём** (`01-repo-standard.md` §4.5). Все `.docx` конвертированы в `.md`
   с полным текстом: 17 конспектов встреч с психологом → `02-clinical/psychologist-sessions/`,
   «Приятное №3» → `08-feedback/pleasant-words/pleasant-3-text.md`, два прежних портрета →
   `10-archive-analysis/04-deliverables/`. Оригиналы `.docx` остаются во внешнем архиве проекта.
4. **Замороженное не переписано.** В `09-history/` и `04-deliverables/` ссылки и текст оставлены
   как были (`21-revision-protocol.md` §1). Перелинковка выполнена только в активных файлах блока.

## Аудит целостности

Сверка каждого файла инфраструктуры проекта с деревом репы по `md5`:

```
байт-в-байт ......... 80 файлов
конвертировано ...... 20 файлов (.docx/.pdf → .md, полный текст)
ПОТЕРЯНО ............  0
```

## Что осталось внешним

Картиночные источники (Instagram, VK, переписки, vkgraph) в репу не кладутся: это скриншоты,
режим A по ним возможен **только прямым вложением PDF в чат** (`../00-protocol/03-channels.md`).
Правило канала не изменилось.
