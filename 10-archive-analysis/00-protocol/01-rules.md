# 01 — ПРАВИЛА РАБОТЫ
> Версия **3.0** · 14.07.2026. Заменяет: `00_ГЛАВНЫЕ_ПРАВИЛА.md`, `МЕТОДИКА_анализа.md`, `РЕЖИМЫ_анализа.md`, `ЧЕКЛИСТ_ревизии.md`.

## §1. ПЯТЬ ПРАВИЛ (не обсуждаются)

### 1. Заметки заменяют источник
Каждая реплика — **дословно, в кавычках**. Все даты, имена, таймстемпы, реакции, вложения с размерами, пометки `edited`, номера pinned.
Критерий: *по заметкам можно вести анализ, не открывая оригинал.*
**Пересказ = брак. «Там комплименты» = брак.**

### 2. Только режим A
Каждая страница просматривается **глазами, целиком, по одной**.
Никаких «B» и «C», никакого чтения по OCR, никакого «пролистал и ухватил суть».
Молчаливое сползание в дешёвый режим — **самый тяжёлый вид брака**, потому что снаружи выглядит как работа.

### 3. Не говорить «не могу», не перепробовав всё
Прежде чем объявить что-то невозможным — исчерпать варианты. Все. Список уже проверенного — в §4.
Преждевременное «это нечитаемо» — нарушение.

### 4. Честный учёт
- Не прочитал → **сказать**, а не размазать.
- Нечитаемо → пометить `[НЕЧИТАЕМО]` прямо в заметках.
- Не уверен, кто говорит → `[АТРИБУЦИЯ НЕТОЧНА]`.
- Взял из прошлого саммари, а не из документа → **сказать явно**.
**Овербкейм — отдельный тип ошибки. Отслеживается.**

### 5. Паспорт качества — на каждый документ
В конце файла заметок, обязательно:
режим · прочитано X/Y страниц · что взято · **ограничения списком** · **честная оценка /100**.
Без паспорта документ не считается обработанным.

### 6. 🔴 СТАРЫЕ ЗАМЕТКИ — НЕ ЗАМЕНА ЧТЕНИЮ

**Каждый файл корпуса проходится ЗАНОВО, в режиме A.** Прежние наработки
(`Заметки_Клода_по_всем_файлам.md`, `Заметки_по_файлам_Василий.md`, `Портрет_ФИНАЛ.docx`, `Vasily_Analysis_2026.docx`)
— **справочный материал и источник гипотез. Не источник правды.**
В них **≥9 подтверждённых ошибок** (см. `01-registry/facts-and-hypotheses.md` §3).

**Файл считается закрытым только если:**
1. Пройден в **режиме A** · 2. Заметки **дословные** · 3. Есть **паспорт качества** · 4. **Оценка ≥ 85/100**

**Всё, что ниже 85, — переделать. «Прочитано по старым заметкам» = НЕ прочитано.**
Опираться на прежний вывод, не проверив по источнику, — **овербкейм. Брак.**

### 7. 🔴 КАЖДЫЙ ФАЙЛ — В СВОЁМ ОПТИМАЛЬНОМ КАНАЛЕ

Режима A **недостаточно**. Файл должен быть ещё и **доставлен правильным каналом** — иначе режим A физически невозможен.
Канал определён экспериментом 14.07.2026 (`00-protocol/03-channels.md`) и **не обсуждается**:

| Класс | Канал | Правило |
|---|---|---|
| 📄 **ТЕКСТ** (35 файлов) | **Файлы проекта** | Читать оттуда. Бесплатно, безлимитно |
| 🖼 **КАРТИНКИ** (16 файлов) | **PDF напрямую в чат. БЕЗ АРХИВА. НЕ через проект** | **Работа НЕ НАЧИНАЕТСЯ, пока файл не приложен напрямую** |

**🚫 ЗАПРЕТ.** По визуальному источнику (Instagram, VK, рукописный дневник, Приятное, поздравление, брат, vkgraph)
**НЕЛЬЗЯ начинать анализ**, пока Василий не прислал PDF **прямым вложением в сообщение**.

Ни из проекта. Ни из архива. Ни по OCR. Ни по старым заметкам.
**Нет прямого вложения → файл не в работе. Точка.**

Попытка «начать по тому, что есть» — **брак**, потому что даёт иллюзию покрытия там, где источник не читался.

## §2. ПРОЦЕДУРА

**Заметки писать батчами по 3–4 страницы, сразу в файл.**
Не копить до конца. Проверено: после 10+ страниц привязка «какая реплика на какой странице» разваливается.

**Чат держать чистым.** Бюджет — контекст, а не количество картинок.
- Вывод bash — короткий. Большие тексты в stdout не гнать.
- Свои же заметки обратно в контекст не перечитывать.
- `MEGA_HANDOFF` целиком не открывать. Только грепом.

**Принял вахту → порядок действий:**
1. `index.md` → 2. `00-protocol/01-rules.md` → 3. `watchlog.md` (§Где стоим) → 4. `01-registry/corpus-inventory.md` (проверить файл эмпирически, названия врут) → 5. Работа → 6. Обновить WATCHLOG → 7. Отдать архив.

**Не верить саммари. Верить файлам.** Прошлые хендоффы содержали ошибки — 8 штук задокументировано.

2. **Версионирование по SemVer.** Батч чтения = `PATCH`; новый источник закрыт или новый блок =
   `MINOR`; смена методологии = `MAJOR`.
3. **Имена файлов — только latin kebab-case** (`00-infrastructure/01-repo-standard.md` §1).
   Кириллица в путях ломается на macOS (NFD/NFC) — это уже стоило времени.
4. **`.docx`, `.zip`, `.pptx` в репу не кладём** — конвертируем в `.md`. PDF-первоисточники
   допустимы до 5 МБ.
5. **Правило «ничего не удаляем» сохраняется** и усиливается: теперь история ещё и в `git log`.
