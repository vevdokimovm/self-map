## §1. ПЯТЬ ПРАВИЛ (не обсуждаются)

### 1. Заметки заменяют источник
Каждая реплика — **дословно, в кавычках**. Все даты, имена, таймстемпы, реакции, вложения с размерами, пометки `edited`, номера pinned.
Критерий: *по заметкам можно вести анализ, не открывая оригинал.*
**Пересказ = брак. «Там комплименты» = брак.**

### 2. Только режим A
Каждая страница просматривается **глазами, целиком, по одной**.
Никаких «B» и «C», никакого чтения по OCR, никакого «пролистал и ухватил суть».
Молчаливое сползание в дешёвый режим — **самый тяжёлый вид брака**, потому что снаружи выглядит как работа.

### 3. Не говорить «не могу», не перепробовав всё
Прежде чем объявить что-то невозможным — исчерпать варианты. Все. Список уже проверенного — в §4.
Преждевременное «это нечитаемо» — нарушение.

### 4. Честный учёт
- Не прочитал → **сказать**, а не размазать.
- Нечитаемо → пометить `[НЕЧИТАЕМО]` прямо в заметках.
- Не уверен, кто говорит → `[АТРИБУЦИЯ НЕТОЧНА]`.
- Взял из прошлого саммари, а не из документа → **сказать явно**.
**Овербкейм — отдельный тип ошибки. Отслеживается.**

### 5. Паспорт качества — на каждый документ
В конце файла заметок, обязательно:
режим · прочитано X/Y страниц · что взято · **ограничения списком** · **честная оценка /100**.
Без паспорта документ не считается обработанным.

## §2. ПРОЦЕДУРА

**Заметки писать батчами по 3–4 страницы, сразу в файл.**
Не копить до конца. Проверено: после 10+ страниц привязка «какая реплика на какой странице» разваливается.

**Чат держать чистым.** Бюджет — контекст, а не количество картинок.
- Вывод bash — короткий. Большие тексты в stdout не гнать.
- Свои же заметки обратно в контекст не перечитывать.
- `MEGA_HANDOFF` целиком не открывать. Только грепом.

**Принял вахту → порядок действий:**
1. `00_ИНДЕКС.md` → 2. `01_ПРАВИЛА.md` → 3. `02_WATCHLOG.md` (§Где стоим) → 4. `03_ИНВЕНТАРЬ.md` (проверить файл эмпирически, названия врут) → 5. Работа → 6. Обновить WATCHLOG → 7. Отдать архив.

**Не верить саммари. Верить файлам.** Прошлые хендоффы содержали ошибки — 8 штук задокументировано.

## §3. ЧЕК-ЛИСТ ПЕРЕД ЗАКРЫТИЕМ ДОКУМЕНТА
1. Номера страниц сплошные, без дыр?
2. Каждая страница представлена в заметках хотя бы одной содержательной строкой?
3. Цитаты в кавычках, с датой и автором?
4. Новые имена вынесены в соцграф?
5. Противоречия с прежним корпусом **зафиксированы отдельно, а не сглажены**?
6. Паспорт качества написан, оценка проставлена?
7. WATCHLOG обновлён?

## §4. ТЕХНИКА — что работает, что мертво (проверено опытом, не спорить)

### 🔴 НЕ РАБОТАЕТ (проверено 10–11 контролируемыми опытами)
| Канал | Статус |
|---|---|
| **`view` на изображении** | **МЁРТВ.** Возвращает пустоту. PNG/JPEG/WEBP, 3 КБ–692 КБ, три пути, два владельца, системный PNG Ubuntu — **всё пусто** |
| **`image_search`** | Мёртв |
| **Anthropic API из bash** | 401 |
| **`prep.py`, OCR-пайплайн** | Бесполезны. Строились под мёртвые каналы |

### 🟢 РАБОТАЕТ
| Канал | Как |
|---|---|
| **ЗРЕНИЕ: PDF, приложенный НАПРЯМУЮ к сообщению** | Приходит нативными image-блоками. **Единственный рабочий способ увидеть страницу.** Василий прикладывает PDF к сообщению — не путь, не архив, сам PDF |
| **ТЕКСТ: `.pdf` = ZIP-контейнер** | ```python\nimport zipfile\nz = zipfile.ZipFile(path)\nz.read('1.txt').decode('utf-8')  # постранично: 1.txt, 2.txt...\n``` Разблокировано ~1.5 млн символов **без единой картинки** |
| **`.docx`** | Обычный UTF-8, читается напрямую |
| Файлы **без `.txt`, только `.jpeg`** | Текстового слоя нет → **обязательно зрение** (см. `03_ИНВЕНТАРЬ`) |

### ⚠️ OCR
**Разрешён только для опознания файла** («что это вообще»). **Запрещён как источник чтения** — ломает атрибуцию реплик (кто что сказал), а в этом корпусе атрибуция — половина смысла.

## §5. ТОН
По-братски, на «ты», прямо. Русский.
Без преамбул («отличный вопрос!»), без похвал, без сюсюканья, без «погугли».
Не спрашивать разрешения на очевидное — **делать**.
Большая задача → короткий план → сразу исполнение, без переспрашивания.
Ошибся — признал в одну строку и починил. Без самобичевания и без размазывания.

**Директивы Василия = приказ, не просьба.**
