# self-map

Личный атлас: психологический профиль, характер, интеллект, вера. Всё, что описывает меня как личность — собрано в одном месте, а не разбросано по устройствам.

> ⚠️ **Приватный репозиторий.** Здесь личные и клинические материалы. Не делать публичным.

---

## Структура

| Папка | Что внутри |
|-------|-----------|
| `01-psychological-profile` | Аналитические разборы: психологический портрет, тень, подличности (IFS), терапевтическая карта, корни самопознания, работа со стыдом |
| `02-clinical` | Клинические материалы: тест MMPI и психологические заключения |
| `03-competency-reports-rsv` | Отчёты РСВ «Центры компетенций»: жизнестойкость, клиентоориентированность, лидерство, мотивационно-ценностный профиль, личностные опросники, словарный запас |
| `04-genetics-genotek` | ДНК-анализ Genotek: генетическая книга, разбор по психике/физике/витаминам, питание и нутриенты, внутренняя сила |
| `05-faith` | Вера: договор веры, дневник исповеди, скрипт генерации аудио-молитвы |
| `06-diaries` | Дневники: наблюдение за снами + рукописный «материальный дневник» (сканы, 162 стр.) |
| `07-self-reflection` | Личные тексты о себе: «Книга возвращения к себе» (+черновик), Модуль 9 |
| `08-feedback` | Обратная связь обо мне от других людей (опрос, CSV) |
| `09-session-summaries` | Саммари психологических чатов — для переноса контекста между сессиями |
| `10-archive-analysis` | **Сквозной разбор личного архива 2018–2025 в режиме A** (проект «Cowork»): правила и протокол, реестр фактов и гипотез, дословные заметки по источникам, отчёты, прежние портреты |
| `99-misc` | Разное: to-do списки |

---

## Заметки по организации

- **Имена файлов** почищены от мусора автогенерации (UUID-хвосты в отчётах РСВ, битая транслитерация, опечатки).
- **Дедупликация:** материальный дневник лежал в двух вариантах разбивки (2 части / 3 части) — оставлен вариант на 2 файла. Обратная связь дублировалась в 3 копиях — оставлена одна.
- **Саммари** переведены в `.md`, чтобы GitHub рендерил их как текст.

## Версионирование

Репа версионируется по SemVer с v1.0.0 (18.07.2026): `VERSION` → тег `vX.Y.Z` → GitHub Release,
описание берётся из `CHANGELOG.md`. Выпуск одной командой: `zsh publish.sh --minor`.
Правила — `00-infrastructure/25-versioning-and-releases.md`.

**Точка входа для работы:** `WATCHLOG.md` §0 (журнал репы) → далее по блокам.
Для архивного анализа — `10-archive-analysis/README.md` и его `watchlog.md`.

## Заметка о достоверности

`01-psychological-profile/` и `10-archive-analysis/04-deliverables/` писались **до** сквозного
перечитывания корпуса в режиме A и содержат подтверждённые ошибки. Это справочный материал и
источник гипотез — **не источник правды**. Проверенные утверждения живут в
`10-archive-analysis/01-registry/facts-and-hypotheses.md` со ссылкой на первоисточник.
