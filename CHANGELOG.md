## [1.12.0] — 2026-08-27 — Веб-приложение навигации по анамнезу (MINOR)

По заказу владельца, дословно: *«self-map тоже самое сделай чтобы можно было легко
смотреть весь всесторонний анамнез моей жизни во всех аспектах»* (по аналогии с

### Added
- `web/` — React 19 + Vite + TypeScript, чисто клиентское, без бэкенда, без сети,
  порт 5185. Три страницы: **Разделы** (12 карточек с живым счётом файлов и
  описанием из MANIFEST), **Реестр фактов** (парсинг `10-life-history/01-registry/
  facts-and-hypotheses.md` — 42 записи, 5 разделов, статус-глифы как эвристический
  маркер, не интерпретируются как факт их семантики), **Поиск** (фильтр по именам
  файлов внутри разделов, не полнотекстовый).
- Верификация: `npm install` (72 пакета, 0 уязвимостей) → `tsc -b` (0 ошибок) →
  `npm run build` (успех, 239 КБ JS / 4.5 КБ CSS gzip) → dev-сервер + `curl` на
  всех эндпоинтах (671 файл по 12 разделам, 5/42 разделов/записей реестра
  подтверждены) → сервер остановлен.

### Deliberately not done
- **Даты в реестре фактов не унифицированы достаточно для календарной хронологии**
  — записи остаются в порядке документа, UI прямо об этом сообщает вместо того,
  чтобы придумывать даты.
- **Главные экраны не показывают содержимое** — только названия файлов/заголовки
  записей. Полный текст — только по явному клику. Решение по чувствительности
  материала (психологический профиль, клиника, дневники).
- Поиск — только по именам файлов, не полнотекстовый (за пределами MVP).

## [1.3.1] — 2026-07-18 — Починка `fix_release_notes.sh` под zsh (PATCH)

### Fixed

- **`fix_release_notes.sh` не правил ничего в режиме `--all`.** Список версий собирался в строку
  и обходился через `for V in $VERSIONS` — но **в zsh нет word splitting для unquoted переменных**
  (в отличие от bash), поэтому вся строка `1.0.0 1.1.0 1.2.0 1.3.0` попадала в цикл **одним**
  элементом: `gh release view "v1.0.0 1.1.0 1.2.0 1.3.0"` → «релиза нет, пропускаю» → «исправлено 0».
  Скрипт с шебангом `bash`, но запускается через `zsh ./script.sh` — семантика zsh, не bash.
  **Исправлено:** список пишется в файл и читается `while IFS= read -r V ... done < "$VLIST"`
  (редирект из файла, а не пайп — иначе subshell съедает счётчики). Работает в обеих оболочках.
  Проверено прогоном цикла: 4 итерации, счётчик переживает цикл.

### Added
