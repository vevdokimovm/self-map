# 🗂️ Карта репозиториев

> GitHub: [vevdokimovm](https://github.com/vevdokimovm) — личная система хранения. Одна репа = одна зона жизни, зоны не пересекаются.

> **Все репы — приватные и сугубо личные.** Это персональная система для удобного анализа и поддержания актуальности информации, а не витрина для чужих глаз. Поэтому сюда грузится **всё**, включая любые персональные данные: риски осознаны и приняты, данные мои. **Единственное железное исключение — секреты:** пароли, приватные ключи, API-токены, данные банковских карт и всё, что при утечке открывает доступ к деньгам или аккаунтам. Их — никогда, даже в приватную репу.

> 📍 Эта карта живёт в **`base-repo`** — родительской репе всей системы.

## 📅 Статус карты

| Поле | Значение |
|---|---|
| **Версия карты** | 2.1.0 |
| **Актуальность:** | 2026-08-12 |
| **Проверена целиком** | 2026-07-24 |
| **Сопровождение** | полуавтоматическое — `templates/deploy.sh` сам регистрирует новые репы |
| **История изменений** | [`repos-map-CHANGELOG.md`](./repos-map-CHANGELOG.md) |

> **Как читать статус.** «Актуальность» — дата последнего касания карты (её проставляет и скрипт).
> «Проверена целиком» — когда карту последний раз сверяли с GitHub глазами. Если между ними
> больше ~2 месяцев — карта могла отстать, пройдись по списку реп.
>
> **Имя файла и путь неизменны** (`base-repo/repos-map.md`) — на карту ссылаются другие доки,
> поэтому версионируется содержимое, а не имя. Что менялось — в changelog рядом.
>
> **Репы с 🆕 и пометкой «НЕ ОПИСАНА»** заведены автоматически деплойером: он создал репу под
> новый архив и зарегистрировал её здесь заглушкой. Твоё дело — дописать зону ответственности
> и убрать маркер.
