## Схема разбора

У всех одна и та же, чтобы файлы были сравнимы:

1. **Путь** — что с ним произошло по сюжету, без трактовок
2. **Психология** — как он устроен: защиты, привязанность, искажения мышления
3. **Что берётся** — работающее, с переводом на обычную жизнь
4. **Чем травит** — обязательный пункт, не оговорка ради приличия
5. **Что с этим делать** — действие, а не вывод
6. **Проверочный вопрос** — одна строка, которую можно себе задать

## Порядок чтения

Начинать с **Кенни**, а не с Эрена. Кенни появляется поздно и главным героем
не является, но произносит тезис, к которому сводится всё произведение:
свободных нет, есть только выбор хозяина. Все остальные — пятнадцать разных
ответов на его вопрос.

Дальше в любом порядке. Если нужен один — бери того, чей проверочный вопрос
сейчас неприятнее всего.
