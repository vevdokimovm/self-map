# _archive — прежние вариации деплой-скриптов (НЕ ЗАПУСКАТЬ)

> **Все они заменены одним `templates/deploy.sh`.** Здесь лежат только как история решений:
> откуда взята каждая механика и почему сведены в один. Разбор — `reports/merges/scripts_consolidation_report.md`.

Запускать что-либо отсюда — значит наступить на уже исправленные грабли (в частности PIT-014:
тег на старом дереве). Единственный рабочий скрипт системы — `templates/deploy.sh`.

| Файл | Что умел | Что из него взято в `deploy.sh` |
|---|---|---|
| `deploy_all_versions.sh` | батч всех версий всех реп из папки | **скелет**: инвентаризация, группировка, SemVer-сортировка, PIT-защиты, `ASSETS_ONLY`, `BACKFILL` |
| `publish.sh` | цикл бамп→коммит→тег→пуш→релиз внутри клона | питон-парсинг CHANGELOG в `--notes-file`, ретраи, режим доделки |
| `deploy_from_zip.sh` | публикация ОДНОГО архива снаружи | маркеры корня, разворот обёртки, автопроверка «файлов в коммите == в дереве» |
| `push_archives.sh` | ассеты + описания релизов | идемпотентность релизов, `FORCE`/`NOTES_ONLY`, защита от перезаливки готового |
| `deploy_all.sh` | ранний батч | — (поглощён `deploy_all_versions.sh`) |
| `commit_to_main.sh` | просто коммит+пуш | — (частный случай) |
| `commit_all_versions.sh` | коммиты по версиям без релизов | — (источник бага «закоммичено, но релиза нет») |
| `push_base_repo.sh`, `sync-all.sh` | заливка именно base-repo | разворот обёртки (PIT-007) |

Правило: **новую вариацию не создаём.** Нужна новая механика — она добавляется в `deploy.sh` флагом.
