## Находка — не серия, а разложить руками

Кадры — не одна тема, а вперемешку сфотографированы медицинские документы минимум
трёх разных людей (твои — под военно-врачебный случай, плюс ещё две родственницы
с разными фамилиями, разные диагнозы разных лет). `METHOD_IMAGES.md` §3 требует
серию «одного предмета, одного объекта съёмки» — здесь предмета нет, это случайная
подборка из общего фотопотока телефона.

**Решение: заметку по этой папке не писать.** Записывать диагнозы третьих лиц в файл
базы, когда неясно, где им место (`family`? отдельная папка? не в этой репе вообще?) —
решение владельца, не моё. Записано в `TASKS.md` (раздел про `legal-knowledge-base`).

## Допущение по масштабу — что дальше

`221 серия / 1650 кадров` — на порядок больше потолка «100 изображений на чат»
(`METHOD_IMAGES.md` §10): это не одна сессия и не один авто-заход, а многонедельная
кампания, как документы (`docs_to_md.py`) были 22→23→27.08.

**Решение: не продолжать очередь целиком в этом авто-заходе.** Причины:

1. Крупнейший блок очереди (`portrait-of-taste/photos*`, ~80+ серий) — фотографии
   именованных живых людей для личного проекта владельца («портрет вкуса»);
   писать «0a дословный захват» по внешности конкретных людей без владельца
   рядом — решение не для автономного ночного прогона, даже при том что владелец
   сам спроектировал этот метод для этой же репы 08.08.2026.
2. Второй крупный блок (`misc-vault/.../Дневник рефлексий Notion/photos/`,
   ~15 серий) — личный психологический дневник владельца за 2021 год: то же
   соображение, чтение и синтез такого материала лучше с владельцем на связи.
3. Первая же попытка (см. выше) сразу нашла проблему с данными, которую нельзя
   решить без владельца — плохой знак для продолжения по инерции без проверки.

**Что безопасно и стоит продолжить БЕЗ владельца** (следующий заход): чисто
технические серии без личных фото — диаграммы (`academic-portfolio/*/diagrams`,
`master-admission/*/Диаграммы`, `personal-finance-dss/docs/diagrams`),
скриншоты кода (`it-base/*/screenshots`), сканы сертификатов
(`academic-portfolio/07-certificates/scans`), игровые скрины (`dota-dossier`).
Это меньшая, но реальная часть очереди — не считано отдельно в этом заходе.
