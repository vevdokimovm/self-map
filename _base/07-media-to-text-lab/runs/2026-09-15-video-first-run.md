## Качество — по участкам, а не в среднем

| участок | что | оценка |
|---|---|---|
| 00:00–04:20 | связное объяснение правила | 🟢 смысл целиком, искажения отдельных слов («вдохательное», «дохов») |
| 04:20–11:17 | счёт под дыхание, мало слов | 🔴 модель `base` путает и **галлюцинирует повтор** («Пятый вдох, шестой» ×9 за 8 секунд) |
| упражнения 05:00–07:00 | названия | 🟡 восстановлены **по кадрам**, не по речи |

> 🔴 **Кадры спасли то, что потеряла речь.** Без досева кадров вторая половина видео
> осталась бы галлюцинацией распознавания без проверки.

## Три поломки, найденные прогоном

1. **Ложный успех на несуществующем файле.** Путь из служебки устарел (`~/Documents/_heavy-originals/`,
   а файл в `reports/imports/heavy-originals/`), ffmpeg не открыл файл — скрипт написал 🟢 и пустую
   заметку. Починено: нет файла или длительность 0 → код 1.
2. **Два кадра на 11 минут.** Детектор смены сцены молчит при неподвижной камере. Починено:
   паузы длиннее `--every` (60 с) досеваются кадрами, канарейка проверяет досев.
3. **Установка упала молча.** `brew install … | tail` вернул 0 при ошибке загрузки — хотспот рвал
   HTTP/2. Повтор с HTTP/1.1 и ретраями прошёл.
