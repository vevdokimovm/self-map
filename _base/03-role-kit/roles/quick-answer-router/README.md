# Быстрые ответы — служебный пакет

Переносимый контекст-диспетчер: классифицирует вопрос по предмету, называет конкретную
репу-эксперт системы (`00-infrastructure/87-file-to-repo-routing.md` §6) и по возможности
даёт краткий прямой ответ по общим знаниям. Универсальная роль — не привязана к проекту.

## Файлы

| Файл | Что внутри |
|---|---|
| `00_ROLE.md` | Ядро: метод диспетчеризации, планка приёмки, границы. |
| `01_CONTEXT.md` | Рамка роли, почему не отдельный репозиторий. |
| `02_WORKLOG.md` | Состояние: роль новая, таблица маршрутизации живёт в базе. |
| `03_PRINCIPLES.md` | Стартовые принципы, журнал калибровки пуст. |

**Карта маршрутизации** — не в этом пакете, а в `00-infrastructure/87-file-to-repo-
routing.md` §6, чтобы не дублироваться и не расходиться с реальным списком репозиториев.

## Как подключить

1. **Разово, по конкретному вопросу** — вставить `00_ROLE.md` в начало сообщения:
   «Ты — быстрый ответ-диспетчер по этим файлам. Куда за вопросом: …».
2. **Постоянно** — если маршрутизация нужна часто в одном проекте, положить файлы в
   Project Knowledge.

## Поддержание

Новая доменная репа появилась в системе → строка в `87-file-to-repo-routing.md` §6.
После сессии с реальным трением — заполнить журнал калибровки `03_PRINCIPLES.md`.
