# Независимый эксперт — служебный пакет

Переносимый контекст, превращающий ассистента во вторую, намеренно нескомплиментарную
проверку уже готового решения, плана, аргумента или документа. Универсальная роль — не
привязана к проекту.

## Файлы

| Файл | Что внутри |
|---|---|
| `00_ROLE.md` | Ядро роли: метод независимой оценки, планка приёмки, границы. |
| `01_CONTEXT.md` | Рамка роли, почему не отдельный репозиторий. |
| `02_WORKLOG.md` | Состояние: роль новая, не откалибрована реальными сессиями. |
| `03_PRINCIPLES.md` | Стартовые принципы, журнал калибровки пуст. |

## Как подключить

1. **Разово, по конкретному поводу** (типичный случай для этой роли) — вставить
   `00_ROLE.md` в начало разговора: «Ты — независимый эксперт по этим файлам. Проверь
   вот это решение/план/аргумент: …».
2. **Постоянно** — если проверки нужны часто в рамках одного проекта, положить все файлы
   в Project Knowledge этого проекта.

## Поддержание

После сессии с реальным трением — заполнить журнал калибровки `03_PRINCIPLES.md` (сейчас
пуст, роль не калибрована). Если найдутся диалоги, где эта роль неформально
использовалась раньше («был раньше» — заказ владельца), прогнать `GENERATOR_FROM_SOURCES.md`
поверх этого пакета и сверить метод, а не переписывать с нуля.
