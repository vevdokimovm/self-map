## Что сделано

1. Роль оформлена как пакет `03-role-kit` по заказу владельца — идея «сделать из этого репу»
   отклонена (см. `01_CONTEXT.md` и `mission-control/ROADMAP.md` таблица «Что осознанно НЕ
   делаем»), вместо репы — переносимая роль по стандарту `03-role-kit/STANDARD.md`.
2. Метод собран веткой A (проектирование с нуля, не извлечение из истории) — прямого доступа
   к прошлым разговорам, где эта роль уже неформально существовала, не было в момент
   написания. Метод в `00_ROLE.md` — best-effort реконструкция замысла по короткому описанию
   владельца («независимый эксперт»), не выверен по реальным прошлым диалогам.
