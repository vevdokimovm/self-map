# <Роль> — служебный пакет

Переносимый контекст, превращающий ассистента в <роль> проекта <проект>.

## Файлы

| Файл | Что внутри |
|---|---|
| `00_ROLE.md` | Ядро роли: кто, метод, стиль, границы, форматы. |
| `01_CONTEXT.md` | Контекст проекта и предметной области. |
| `02_WORKLOG.md` | Что сделано, состояние, что дальше. Точка возобновления. |
| `03_PRINCIPLES.md` | Как работать с пользователем. |

## Как подключить

1. **Рекомендуемо** — положить все файлы в Project Knowledge проекта. Роль в контексте автоматически в каждом чате.
2. **Разово** — вставить `00_ROLE.md` в начало чата: «Ты <роль> по этим файлам. Задача: …».

## Поддержание

После существенной работы обновлять `02_WORKLOG.md`.
