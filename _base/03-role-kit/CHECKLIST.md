# Приёмка роли

Прогнать перед тем, как класть роль в проект.

## Структура
- [ ] 4 файла + README, нумерация `00`–`03` соблюдена.
- [ ] Паспорт в шапке `00_ROLE.md` заполнен (role, project, version, updated, scope).
- [ ] Нейминг папки: `kebab-case`, проектная — с суффиксом проекта.

## Метод (главное)
- [ ] Метод описан как **способ рассуждения**, а не список знаний.
- [ ] 4–6 пунктов, каждый проверяем и влияет на выдачу.
- [ ] Есть характерное разделение домена (что ↔ что различает профессионал).
- [ ] Для быстроменяющегося домена — есть пункт про сверку актуальности.
- [ ] Нет пустот вроде «будь профессионалом», «учитывай все факторы».

## Планка приёмки
- [ ] Секция есть, 3–5 проверяемых условий формата «ответ не закончен, пока не…».
- [ ] Есть обязательные действия (сверка актуальности / проверка альтернативы / расчёт), а не только намерения.
- [ ] Есть требование честно маркировать уровень уверенности и отделять проверенное от общих знаний.
- [ ] Роль не поощряется звучать увереннее, чем обоснована.

## Границы
- [ ] Секция границ есть и конкретна.
- [ ] Сформулированы без самоуничижения и без отфутболивания.
- [ ] Отделены физические ограничения, зона ответственности человека и этические линии.
- [ ] Границы не превращают роль в отказную машину — в своей зоне роль работает полностью.

## Антипаттерны
- [ ] Роль не требует всегда соглашаться и хвалить.
- [ ] Роль не требует обманывать, подделывать данные или скрывать риск от пользователя.
- [ ] Нет дублирования общих преференций.
- [ ] Нет абзацев, которые ничего не меняют в поведении.

## Если роль собрана извлечением (ветвь B)
- [ ] Источники реально прочитаны, а не угаданы по названиям; история чатов искалась поиском.
- [ ] Каждый существенный пункт помечен: `[источник]` / `[реконструкция]` / `[предположение]`.
- [ ] Есть сводный честный аудит — что откуда взято.
- [ ] Нет выдуманных «зафиксированных решений», которых нет в материалах.
- [ ] Секции без материала помечены как незаполненные, а не разбавлены водой.
- [ ] Пробелы собраны в список вопросов и заданы.

## Калибровка
- [ ] В `03_PRINCIPLES.md` есть блок **неизменяемого ядра** (честность, право возражать, непроверенное не выдавать за факт, границы).
- [ ] Записанные предпочтения имеют **контекст/условие**, а не сформулированы как безусловный закон.
- [ ] Записи не противоречат друг другу и не устарели.

## Практика
- [ ] `03_PRINCIPLES.md` отражает реальную обратную связь, а не общие слова.
- [ ] `02_WORKLOG.md` даёт понятную точку возобновления.
- [ ] «Чужие зоны» помечены так, что не читаются как пробелы роли.
- [ ] Форматы выдачи заданы явно.

## Боевая проверка
- [ ] Загрузил в тестовый чат, дал реальную задачу — поведение соответствует методу.
- [ ] Задал вопрос на границе — роль ответила честно и по делу, без отказа и без переоценки себя.
- [ ] Внесена строка в `CATALOG.md`.
