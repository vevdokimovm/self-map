# CHECKLIST — приёмка прогона синтеза

> Проходится дважды: **до** первой мутирующей операции и **на закрытии**.
> Непройденный пункт — стоп, а не «потом допишем».

---

## A. До старта — допуск

- [ ] `ANTHROPIC_API_KEY` установлен (mission-control:ADR-010: только коммерческие условия)
- [ ] Рабочий каталог содержит **только открытую зону** — 🔴 `health-vault`
      и `legal-knowledge-base` физически отсутствуют
- [ ] 🟡-репы (`self-map`, `christ-walk`, `family`, `truth-seeking`) в область не входят
- [ ] Прочитан `PITFALLS.md` целиком
- [ ] Прочитан `tools/README.md` — нужный инструмент уже существует?
- [ ] Проверен `mission-control/TASKS.md` / `ROADMAP.md` / `*_HISTORY.md`:
      задача не закрыта ли уже
- [ ] Проверены открытые 🔴-пункты по затрагиваемой зоне
- [ ] Заведена папка прогона `runs/<дата>-<имя>/` из `templates/run-log.md`
- [ ] Свободное место на диске проверено
- [ ] Режим разрешений позволяет массовые файловые операции (PIT-015)

## B. Разведка — факты, а не доки

- [ ] Приватность каждой репы снята через `gh repo list`, **не из карты**
- [ ] `BASE_VERSION` собран по всем репам
- [ ] Проверено, не лежат ли два поколения раздачи друг на друге
      (своя `00-infrastructure/` ↔ `_base/00-infrastructure/` по sha1)
- [ ] Карта сверена с GitHub, расхождения записаны
- [ ] Списки предохранителей (`SKIP_MIRRORS`) сверены с фактической видимостью
- [ ] Каждое утверждение о состоянии подкреплено командой

## C. Классификация — до подсчёта

- [ ] Файлы разнесены по классам: per-repo / base-supplied / legacy-base / truly-own / content
- [ ] Дрейф посчитан **только** по base-supplied
- [ ] Кандидаты отфильтрованы от предметного контента

### 🔴 C-бис. Подъём теории — проверка ПО РАЗДЕЛАМ, а не по файлу (`STANDARD.md` §5а)

- [ ] Прогнан поиск опоры на внешние нормы — файл со ссылкой на стандарт почти всегда
      несёт переносимую часть, даже если помечен как продуктовый:
      `grep -lin "ISO \|WCAG\|RFC 2119\|ГОСТ\|IEEE\|EARS\|MoSCoW" <репа>/**/*.md`
- [ ] По каждому найденному файлу: продуктовое — преамбула, а тело? Разделы разного
      класса разделены, переносимое поднято **обобщённым**, без примеров продукта
- [ ] Проверка покрытия сделана **по предмету**, а не по имени файла: совпадение имён
      не доказывает дубль, расхождение имён не доказывает пропуск
- [ ] В базе назван адрес каждого поднятого документа и **записано, что осталось
      в репе и почему** — иначе следующая вахта проверит то же самое заново

## D. Перенос — недеструктивно

- [ ] Скрипт переноса не перезаписывает: занят путь → рядом с суффиксом + лог
- [ ] Секреты не переносятся; найден живой токен → **отозван у провайдера**, потом чистка
- [ ] Персональные данные третьих лиц проверены до переноса
- [ ] Тяжёлое/непереносимое свёрнуто в служебку, оригинал удалён
- [ ] Резалось по смыслу набора, не по размеру файла

## E. После переноса — доказательство

- [ ] Пост-дифф множеств: «чего не хватало ДО» vs «ПОСЛЕ»
- [ ] Ни один файл не исчез молча
- [ ] Проверка полноты — после подтверждённого завершения процесса (PIT-014)
- [ ] Сверка с независимым источником, не с «скрипт сказал ok»

## F. Решения по кандидатам

- [ ] По каждому кандидату записано решение: повысить / оставить локальным / удалить
- [ ] Решения оформлены по `templates/candidate-decision.md`
- [ ] Похожие документы **сведены по смыслу**, а не склеены
- [ ] Заполненные документы превращены в шаблоны, а не перенесены как есть
- [ ] Граница `base-repo` / `mission-control` проверена вопросом
      «изменится ли файл, если поменяются цели?»

## G. Раздача

- [ ] `DRY` прогон выполнен и прочитан
- [ ] Ни одна публичная репа базу не получает
- [ ] `.repo-id` удалён, `VERSION` → `BASE_VERSION`, `DO-NOT-EDIT.md` положен (ADR-003)
- [ ] После прогона — цикл по `_base/BASE_VERSION`, никто не отстал
