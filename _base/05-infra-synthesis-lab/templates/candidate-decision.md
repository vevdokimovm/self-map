## `<путь/к/файлу.md>` — `<репа-источник>`

- **Что это:** одна фраза по существу, не по названию.
- **Объём:** N КБ.
- **Встречается в:** сколько реп, совпадает ли содержимое.

**Тест переиспользуемости**

| Вопрос | Ответ |
|---|---|
| Это метод/правило или предметный контент? | |
| Полезно двум и более репам? | |
| Изменится, если поменяются цели владельца? (да → `mission-control`) | |
| Есть ли в базе документ про то же? | |

**Решение:** ⬆️ повысить · 📍 оставить локальным · 🗑 удалить как дубль

**Форма переноса** (если повышаем):

- [ ] как есть
- [ ] переписан в шаблон (был заполненный документ)
- [ ] сведён с `<базовый-файл>` в одну методичку
- [ ] разбит на N документов

**Куда:** `<путь в base-repo>`
**Что делать с оригиналом:** удалить / оставить + указатель на канон / оставить как есть

**Обоснование:** почему именно так. Одно-два предложения — читать будет тот, кто
столкнётся с этим файлом через полгода.
