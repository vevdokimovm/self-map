## Как заводить прогон

1. Папка `runs/<ГГГГ-ММ-ДД>-<короткое-имя>/`.
2. Внутрь — `README.md` из `../templates/run-log.md` (журнал) и `PLAN.md` (роадмап прогона).
3. Строка в таблицу выше — **сразу**, со статусом «в работе», не после завершения.
4. Решения по кандидатам — `decisions.md` в папке прогона, по
   `../templates/candidate-decision.md`.

## Что обязательно остаётся после прогона

- **Цифры разведки** — сколько реп, в каком состоянии, что с чем разошлось. Без них
  следующий прогон начнёт измерять заново.
- **Решения по кандидатам** — иначе сборщик предложит то же самое, и его снова будут
  разбирать с нуля.
- **Что пошло не так** — с корнем, а не с симптомом. Пополняет `../PITFALLS.md`.
