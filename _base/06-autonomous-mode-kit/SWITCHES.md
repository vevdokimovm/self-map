# SWITCHES — включить и выключить автономный режим

> Один файл, где собраны **все** рычаги. Цель — чтобы включение занимало одну строку,
> а выключение не требовало вспоминать, что именно вчера меняли.

---

## 0. Главное правило переключателей: проектный уровень, не глобальный

**Всё, что относится к автономной работе, пишется в `.claude/settings.json` РЕПЫ,
а не в `~/.claude/settings.json`.**

Причина — не эстетика. Глобальный файл общий на все 57 реп: разрешение, выданное
ради одной, действует во всех, включая закрытую зону. Хуже — **`/auto-mode-setup`
дописывает именно в глобальный файл**, и повторный запуск в другой репе смешивает
контексты безопасности и блокирует массовые файловые операции.

| Уровень | Файл | Когда |
|---|---|---|
| Проект | `.claude/settings.json` | **по умолчанию для всего в этом ките** |
| Проект, личное | `.claude/settings.local.json` | машинозависимое, не коммитится |
| Глобально | `~/.claude/settings.json` | только то, что верно для **всех** реп |

Состояние на 21.08.2026: у базы **нет** проектных настроек, всё лежит глобально
(26 разрешений, `defaultMode: acceptEdits`). Разнести — задача в `ROADMAP.md`.

## 1. Три режима, между которыми переключаются

| Режим | Что значит | Чем включается |
|---|---|---|
| **Диалог** (по умолчанию) | спрашивает на всём, что меняет мир | ничего не делать |
| **Полуавтомат** | не спрашивает на правках файлов, спрашивает на остальном | `defaultMode: acceptEdits` |
| **Автоном** | не спрашивает ни на чём, работает по брифу до стоп-условия | см. §2 |

**Полуавтомат — рабочий дефолт**, и он уже включён глобально. Автоном включается
**на прогон**, а не навсегда.

---

## 2. Включение автонома

### 2.1. В идущей сессии — самый частый случай

Владелец уходит, сессия остаётся с контекстом. Ничего технически переключать не нужно:
автономность здесь задаётся **мандатом в тексте**, а не флагом.

Минимальный мандат — три вещи, без них прогон не автономен:

```
Работай по ROADMAP.md без вопросов. Решения принимай сам, фиксируй в decisions.md.
Стоп-классы — по 06-autonomous-mode-kit/STANDARD.md §2: не публиковать, не удалять
пачкой, не говорить моим голосом, не трогать границы безопасности.
```

Полная форма — `LAUNCH_BRIEF.md`.

### 2.2. Headless — когда сессии нет и владельца нет

```bash
claude -p "$(cat 06-autonomous-mode-kit/LAUNCH_BRIEF.md)" \
  --permission-mode bypassPermissions \
  --output-format stream-json
```

Продолжить прерванный: `claude -p --resume <session-id> "продолжай по брифу"`.

Механика, обвязка, watchdog и Routines — `00-infrastructure/51-autonomous-agent-loop.md`.
Здесь не дублируется намеренно.

### 2.3. Проектные настройки под прогон

```json
{
  "permissions": {
    "defaultMode": "acceptEdits",
    "allow": ["Bash(git status)", "Bash(python3 scripts/*)"],
    "deny": ["Bash(rm -rf *)", "Bash(git push*)"]
  }
}
```

**`deny` важнее `allow`.** Разрешения экономят вопросы, запреты держат стоп-классы
закона 2 механически, а не на памяти агента.

## 3. Выключение

| Что выключить | Как |
|---|---|
| **Автоном в идущей сессии** | написать «стоп» / «дальше спрашивай» — мандат снимается словом, как и выдавался |
| **Цикл `/loop`** | `ScheduleWakeup(stop: true)`; проверить `TaskList`, что не осталось монитора |
| **Routines** | `CronList` → `CronDelete <id>`; рекуррентные сами гаснут через 7 дней |
| **Headless-обвязка** | остановить shell-цикл; `launchctl unload ~/Library/LaunchAgents/…plist` |
| **Проектные разрешения** | удалить `.claude/settings.json` репы — глобальные не затронуты |
| **Remote Control** | закрыть сессию; на телефоне она пропадёт из списка |

**Проверка, что выключилось:** `ListAgents` не показывает живых прогонов,
`CronList` пуст, в `~/Library/LaunchAgents/` нет загруженного плиста.

## 4. Наблюдение за идущим прогоном

| Хочу | Механизм |
|---|---|
| смотреть с телефона / браузера | `/remote-control` → приложение Claude, вкладка **Code**, или `claude.ai/code` |
| пуш, когда доделал или нужен ответ | `/config` → «Push when Claude decides» + «Push when actions required» |
| видеть чужие сессии аккаунта | `ListAgents` |

**Аккаунт в приложении обязан совпадать** с тем, под которым идёт сессия — иначе она
просто не появится в списке. Проверить: `oauthAccount.emailAddress` в `~/.claude.json`.

**Мак должен быть включён.** Уснул — прогон на паузе, проснулся — продолжится.
На ночь: `caffeinate -dis`.

### Аккаунты: где живёт идентичность сессии

Проверено 21.08.2026 по официальной документации + локально на этой машине.

> **Сессия принадлежит тому аккаунту, под которым залогинен CLI. Приложение — клиент:
> оно показывает сессии того аккаунта, под которым залогинено оно.** Чтобы сессию увидеть,
> оба должны совпадать.

| Действие | Что происходит |
|---|---|
| сменить аккаунт **в приложении** | меняется только **чей список смотришь**; сессию это никуда не переносит |
| сменить аккаунт **в CLI** (`/login`) | текущая Remote-Control сессия **рвётся** — она зарегистрирована под старым аккаунтом |
| передать живую сессию другому аккаунту | **невозможно**, команды нет; только закрыть и создать новую |

**Мультиаккаунта в приложении нет** — один за раз, переключение через полный выход
(Settings → тап по почте → Sign out → войти другим). Открытые запросы на эту функцию
висят с марта 2026; будет ли она — **подтвердить не удалось**.

**Как смотреть за несколькими аккаунтами сразу.** На маке — изоляция через
`CLAUDE_CONFIG_DIR` (`50-parallel-accounts-and-admin-orchestration.md`): у каждого профиля
свой логин, несколько сессий идут параллельно в разных вкладках. **На одном телефоне
в моменте виден только один аккаунт**; для нескольких нужны разные устройства.

> ⚠️ На macOS credentials лежат в Keychain, и изоляция по `CLAUDE_CONFIG_DIR` там —
> практика сообщества, **не дословная документация**. Работает, но проверить на своей
> версии перед тем, как полагаться в критичном сценарии.

**Проверить, под каким аккаунтом идёт сессия:** `oauthAccount.emailAddress`
в `~/.claude.json`. Спрашивать не у памяти — там легко ошибиться.

## 5. Чего переключателями сделать нельзя

- **Обойти лимит.** Автологин в другой аккаунт при упоре — не настройка, а обход;
  в ките такого механизма нет и не будет. Правильный ответ — пуш на телефон
  и переключение владельцем.
- **Заставить работать без сети.** Обрыв чинится ретраем и `--resume`, а не флагом.
- **Отменить стоп-классы.** `bypassPermissions` снимает **вопросы**, а не **правила**:
  запрет публиковать держится дисциплиной агента и `deny`-списком, не режимом.
