# roles/ — заготовки ролей под IT-продукт

Три готовые заготовки — только самодостаточное ядро `00_ROLE.md` каждой (паспорт, метод, планка
приёмки, границы, форматы выдачи). Полный пакет роли (4 файла + README) собирается при внедрении
в конкретный проект — по `../../03-role-kit/STANDARD.md`.

| Роль | Когда обязательна | Файл |
|---|---|---|
| `architect-template/` | Почти всегда — держит trade-offs и фиксирует решения в ADR | `00_ROLE.md` |
| `lawyer-template/` | Публичный продукт с персональными данными пользователей | `00_ROLE.md` |
| `security-template/` | Продукт с деньгами или чувствительными персональными данными | `00_ROLE.md` |

**Как внедрить:**
1. Скопировать нужную папку в Project Knowledge проекта (или в `knowledge/roles/<роль>-<проект>/`
   самого проекта, если наследуешь паттерн FINPILOT).
2. Переименовать: `architect-template` → `architect-<имя-проекта>`.
3. В паспорте `00_ROLE.md` заполнить `project: <имя>`.
4. Дописать `01_CONTEXT.md`, `02_WORKLOG.md`, `03_PRINCIPLES.md` по шаблонам
   `../../03-role-kit/templates/`.
5. Зарегистрировать в `../../03-role-kit/CATALOG.md`.

Метод и планка приёмки в `00_ROLE.md` — обобщены из реально работавших ролей FINPILOT
(`architect-finpilot`, `lawyer-finpilot`, `security-finpilot`), обезличены до переиспользуемой формы.
