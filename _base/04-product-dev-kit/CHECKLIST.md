# CHECKLIST — приёмка кита в новом проекте

Прогонять перед первым релизом (не при первом коммите — часть пунктов проверяется, когда уже есть
код и история). Невыполненный пункт — не блокер сам по себе, но должен быть осознанным решением
(зафиксировать в ADR, почему пропущен), а не забытым по умолчанию.

## Конфиги и гейты

- [ ] `.flake8`/`mypy.ini`/`.coveragerc`/`pytest.ini`/`.pre-commit-config.yaml` скопированы,
      версии хуков в `pre-commit-config.yaml` актуализированы (не оставлены плейсхолдерами)
- [ ] `pre-commit install` выполнен, хук реально блокирует коммит с нарушением
- [ ] `make coverage` реально проваливается при покрытии ниже порога (проверено намеренной
      поломкой теста, не поверено на слово)
- [ ] `make preflight` реально проваливается при расхождении VERSION/CHANGELOG (проверено)

## CI

- [ ] `.github/workflows/ci.yml` адаптирован под стек проекта (если не Python)
- [ ] Три тира реально разделены: `fast` блокирует PR, `full`/`deep` не блокируют каждый push
- [ ] Линтеры информационные (или сознательно сделаны блокирующими — с ADR-обоснованием почему)

## Документация

- [ ] `docs/ARCHITECTURE.md` заполнен не шаблонными плейсхолдерами, а реальным содержанием
- [ ] `docs/SECURITY.md` — чек-лист минимума реально пройден по каждому пункту, не оставлен пустым
- [ ] `docs/LEGAL.md` — для публичного продукта заполнен, юрисдикция и статус персональных данных
      названы явно (не «TODO»)
- [ ] `docs/reports/adr/` — минимум 1 ADR (первое стековое или структурное решение)
- [ ] `docs/reports/` подключён к диспетчеру `../00-infrastructure/19-reporting-system.md`
      (папки-типы заведены под реальную потребность проекта, не все 14 сразу)
- [ ] `docs/WATCHLOG.md` заведён, если проект ведётся с нескольких сессий/аккаунтов

## Роли

- [ ] Роли из `roles/` скопированы туда, где реально нужны (архитектор — почти всегда; юрист —
      обязательно для публичного продукта с персональными данными; security — обязательно для
      продукта с деньгами/чувствительными данными)
- [ ] `01_CONTEXT.md`/`02_WORKLOG.md`/`03_PRINCIPLES.md` дозаполнены под конкретный проект,
      не оставлены как `00_ROLE.md` в одиночестве

## Версии

- [ ] `VERSION` + `CHANGELOG.md` заведены с первой записи, SemVer соблюдается с первого релиза,
      не введён задним числом после того, как версии уже разъехались

---

> Кит принят, когда гейты реально блокируют (проверено намеренной поломкой), а не просто
> присутствуют как файлы. Файл без проверенного эффекта — это театр дисциплины, не дисциплина.
