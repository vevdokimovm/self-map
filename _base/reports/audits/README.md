# audits/ — отчёты ревизий репозитория

Здесь лежат **отчёты ревизий** — результаты плановых проходов «доки соответствуют реальности»
(`../../00-infrastructure/21-revision-protocol.md`). Каждый полный проход (оси 1–6, а в code-репе
1–9) оформляется отчётом сюда: что проверено, что найдено, что исправлено, что осознанно оставлено
(флаги владельцу).

Имя файла: `repo_revision_<период>.md` (+ `_delta` для дельта-проходов между полными).

Автогенерация: закрытие вехи / задача владельца на ревизию → отчёт сюда.

> В base-repo папка пустая — наполняется по мере ревизий (в т.ч. самой base-repo).
