## 4. Попутно починено: порча имён `#Uxxxx` в ките

В состоянии v1.4.0 все 25 кириллических имён кита лежали как literal `#U041a…`-файлы (Info-ZIP
распаковал zip без UTF-8 флага, результат закоммичен). Контент цел (сверен с каноном v1.2.0
байт-в-байт). Починено декодером `#U(hex)→chr` + нейминг-ревизией C (имена теперь ASCII kebab-case —
класс проблемы снят навсегда). Кодифицировано: `reports/pitfalls.md` **PIT-009**.
