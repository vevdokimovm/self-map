# merges/ — слияния разошедшихся линий между аккаунтами

Здесь лежат **merge-манифесты и отчёты** о слияниях параллельных линий одного состояния (когда одну
задачу делали разные вахты V/J/M/S). Рабочая процедура с чек-листом и гейтами — `merge_and_fork_guide.md`.
Протокол верхнего уровня — `../../00-infrastructure/22-merge-protocol.md`.

Имя файла: `merge_manifest_<версия>.md` или `merge_<версия>_report.md`.

Ключевой принцип: **консолидация, не переписывание истории**.
