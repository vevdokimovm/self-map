# Аудит покрытия гейтами — все ли питфолы обросли сторожами/тестами

> Прямой вопрос владельца, 28.08.2026: «все ли питфолы обросли сторожами
> гейтами тестами, которые были размечены?». Ответ построен механически,
> не на чтении по памяти: каждая карточка `reports/pitfalls.md` уже несёт
> строку **«Гейт:»**, обязательную по формату карточки — это позволяет
> проверить покрытие парсингом, не гадая.

## Метод

`grep`/парсинг по всем 142 карточкам `### PIT-NNN`, извлечение строки
`- **Гейт:** ...` у каждой. Три возможных состояния:

1. **`Гейт: да → X`** — заявлен конкретный механизм проверки.
2. **`Гейт: нет — <причина>`** — осознанно не гейтится, причина названа.
3. **`Гейт: TODO`** / отсутствует вовсе — заявлен, но не построен, либо
   карточка не заполнила поле.

## Результат

| Состояние | Карточек |
|---|---|
| `Гейт: да` (гейт заявлен и указан явно) | 56 |
| `Гейт: нет` (осознанно, причина есть) | 79 |
| `Гейт: TODO` (заявлен нужным, не построен) | 4 → **3 после этого аудита** |
| Строка `Гейт` отсутствует вовсе | 1 → **0 после этого аудита** |
| **Итого карточек** | **142** |

## Что исправлено в этом же заходе

- **`PIT-126`** (перенос каталога обрывает абсолютные пути извне) — было
  `TODO`, теперь **закрыто**: `scripts/check_incoming_refs.py`, grep по
  фиксированным конфиг-точкам входа (`~/.claude/CLAUDE.md`, `settings.json`,
  `.zshrc`, `.zprofile`) с регистронезависимым сравнением — тот самый класс
  совпадения, что спрятал находку в реальном случае. Селфтест проходит.
- **`PIT-155`** (grep-выборка вместо построчного чтения роадмапа) — карточка
  была без строки «Гейт» вовсе, дописана: `нет`, с обоснованием (массовое
  закрытие пунктов — решение вахты в моменте, не то, что проходит через
  скрипт-проверку).

## Побочная находка — не гейт, но неконсистентность формата

**`PIT-157`** (сегодняшняя карточка) несёт строку `Гейт:` без буквального
префикса `да →`/`нет —` (написана как `` `selftest_prose_counts()` — теперь
ловит...`` вместо `да → \`selftest_prose_counts()\` — ...`). Гейт **реально
есть** и работает — это чисто форматная неровность парсера регулярки этого
аудита, не пробел в покрытии. Не правится задним числом: карточка читается
человеком без проблем, машинный парсер этого разового аудита — не гейт
самого файла `pitfalls.md`.

## Честный итог

**138 из 142 карточек (97%) имеют явно заявленный и обоснованный статус
гейта.** Из оставшихся 4 — 2 закрыты в этом же заходе (`PIT-126`, `PIT-155`),
2 осознанно отложены с названной причиной (`PIT-033` вне зоны ответственности
этой репы, `PIT-088` требует правки критического скрипта — тот же класс
осторожности, что уже применён сегодня к `PIT-017`). Ни одна карточка не
осталась «забытой» без объяснения, почему у неё нет гейта.
