# `reports/salvaged` — вынутое из того, что вот-вот исчезнет

**Заведено 04.09.2026.** Сюда кладётся материал, спасённый из носителя
с истекающим сроком: транскрипт сессии Claude Code стирается через 30 дней,
и продлить нельзя (`99-claude-code-sessions.md` §4).

## 🔴 Это перевалочный пункт, а не дом

Файл здесь — **признак незакрытой работы**. У каждого есть настоящий адрес,
и пока он тут, работа не доделана.

| Почему файл может оказаться здесь | Что с ним делать |
|---|---|
| его дом — **чужая репа**, где сейчас работает другая вахта (`PIT-175`) | передать той вахте, она перенесёт |
| дом ещё не выбран, а срок горит | выбрать адрес и перенести |

**Порядок при спасении:** сначала вынуть, потом решать, куда. Обратный
порядок стоит материала: пока выбирается адрес, носитель истекает.

## Что должно быть в каждом файле

1. **дата спасения и срок носителя** — иначе непонятно, что горело;
2. 🔴 **строка «этот файл лежит не у себя дома»** с настоящим адресом;
3. **что именно спасено и чего в спасённом НЕТ** — граница названа явно,
   иначе следующий читатель примет часть за целое.
