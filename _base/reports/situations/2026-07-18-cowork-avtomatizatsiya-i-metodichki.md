## 2. Что сделали — автоматизация (исходный отчёт настройки)

### 2.1 Подключённые источники

- **Gmail** (`vevdokimovm@gmail.com`) — подключён и включён в чате.
- **Google Calendar** — `vevdokimovm@gmail.com` + мостовые iCloud-календари (Рутины, ВАЖНОЕ, ДЕДЛАЙНЫ,
  Учёба, Таски, Православный/РПЦ). Мост: Apple Calendar → Sharing → Public (`webcal://`) → Google Calendar
  «По URL» (webcal→https).
- **Slack** — не используется как источник (нет аккаунта/выключен), пропущен осознанно.
- **Telegram** — бот создан (`@BotFather`, токен в `.env` 600, не в коде). **Не в автоматизации:**
  egress-прокси песочницы Cowork режет `api.telegram.org` (403 на CONNECT-тоннель) — сетевой allowlist
  инфраструктуры, не обходится ни ботом, ни своим MCP внутри той же песочницы. Обход — официальный
  коннектор в реестре либо поллер на своём VPS.
- **Google Drive / Notion** — подключены, но пусты (доков/WATCHLOG FINPILOT там нет).
- **GitHub** — прямого коннектора в реестре нет; `api.github.com` из bash-песочницы привязан к отдельной
  инфраструктуре Claude Code GitHub Actions (repo-scoped, `add_repo`) и не видит приватные репы вне неё.
  Видимость FINPILOT — только косвенно через письма GitHub Actions в Gmail.

### 2.2 Scheduled tasks (8 штук)

пуш без email.

## 4. Что пошло не так (честно)

- **Сбой канала tool-call на Sonnet.** Классификатор безопасности временно не пускал `Bash` с аргументами
  («temporarily unavailable») — сборка утреннего брифа встала. Не бросили: поставили `send_later` на
  продолжение, дождались восстановления канала (урок `15` §15 / PIT-011 — не заражаться историей, реран).
- **Утренний бриф в 18:30** — расписан на 5:30, но запущен вручную вечером; для разовой доставки это ок,
  но напоминание, что `/morning` завязан на утренний контекст.
- **Пустые Drive/Notion** — дайджесты видят проект только через почту; полноценная видимость WATCHLOG
  требует синка `docs/` в Drive/Notion (открытый шаг).

## 5. Уроки (переиспользуемые)

1. **Scheduled task ≠ локальный cron.** Расписание — только `create_trigger`; `Cron*` умирает с сессией
   (`34` §2). Тихий провал, если перепутать.
2. **Промпт задачи самодостаточен** — свежая сессия не помнит ничего (`34` §3).
3. **Перенос задач = перенос рецепта, не объекта** — задачи account-scoped; манифест в репе разворачивает
   систему на любом аккаунте (`34` §6).
4. **Коннекторы: два «включено»** — `connected` (аккаунт) и `enabledInChat` (сессия); оба нужны (`35` §1).
5. **Egress-стена ≠ «невозможно вообще»**, но кодом изнутри песочницы не обходится (Telegram/GitHub) —
   обход только снаружи (`35` §3).
6. **Корреляция на 2–4 аккаунтах — почти всегда конфаунд** (proton↔Cowork): изолировать фактор до выводов
   (`39` §6, метод `28`).
7. **Анти-дубль перед добавлением:** прежде чем писать «методичку про X», проверить, нет ли её (была `28`).
