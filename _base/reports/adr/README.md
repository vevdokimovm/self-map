# adr/ — Architecture Decision Records

Здесь лежат **ADR** — записи принятых решений с обоснованием и отвергнутыми альтернативами. Шаблон и
правила ведения — `adr_template.md`. Тип «ADR» в диспетчере `../../00-infrastructure/19-reporting-system.md`.

Имя файла: `adr_<NNN>_<тема>.md`. Нумерация **сквозная и неизменная**, без пропусков и повторов.
ADR **неизменяемы**: передумал → новый ADR со статусом `Accepted`, старому — `Superseded by ADR-NNN`.

Автогенерация: принято архитектурное/структурное решение → ADR сюда, без отдельной просьбы
(`../../00-infrastructure/20-knowledge-capture-protocol.md`).
