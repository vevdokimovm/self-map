# 16. Кит документов — PDF, DOCX, EPUB, XLSX из Markdown

**Заведён 14.09.2026** решением владельца: *«так если даже ты путаешься мб
назвать его по другому более обще или разнеси в несколько по смысловым точкам?»*

**Почему отдельно.** Документы жили в `11-presentation-kit/FORMATS.md`. Кит
назывался «презентаций», и сама вахта 13.09 записала в роадмап «генерации нет
нигде», не найдя его. Три разные вещи разнесены по смыслу:

| Кит | Что | Скилл |
|---|---|---|
| `11-presentation-kit` | слайды: структура защиты, Gamma, Canva | `/presentation` |
| `15-image-kit` | изображения: фото через промпт для Gemini, схемы, SVG, гифки | `/image` |
| **`16-document-kit`** | **документы: PDF · DOCX · RTF · TXT · HTML · EPUB · XLSX** | **`/document`** |

Вход одной командой — скилл [`/document`](../.claude/skills/document/SKILL.md).

---

## §0. Исполнитель одной командой

```bash
python3 scripts/make_document.py src.md --to pdf --out <репа>/<каталог>/имя.pdf
```

`--to`: `pdf` · `docx` · `rtf` · `txt` · `html` · `epub` · `xlsx`
(`xlsx` — из markdown-таблицы). `--selftest` — канарейка.

## §1. Документы

| Файл | Что |
|---|---|
| [`FORMATS.md`](FORMATS.md) | таблица возможностей, чем каждый формат собирается, почему без библиотек, PDF, EPUB, XLSX, куда класть собранное — всё с замерами 04.09.2026 |
| [`output/`](output/README.md) | собранные образцы (`ONBOARDING.*`); 🔴 единственный каталог, где хук пропускает `.docx`/`.rtf` |

## §2. Порядок

1. Кто будет читать — чиновник/суд/комиссия → PDF, правка другим человеком → DOCX,
   читалка → EPUB, таблица → XLSX.
2. Исходник `.md` — в репе предмета.
3. Собрать `make_document.py`.
4. 🔴 **Открыть результат и посмотреть глазами** (Read на PDF) до отдачи.
5. Сжатие PDF, если тяжёлый: `gs -sDEVICE=pdfwrite -dPDFSETTINGS=/ebook …`
   (`11-presentation-kit/README.md` §4) — и посмотреть снова.
6. Положить рядом с исходником в репе, не в `~/Downloads` и не в `~/Developer`
   (`FORMATS.md` §4а).

## §3. Чего этот кит НЕ делает

- **не пишет содержание** — форма и сборка, суть от автора;
- **не делает картинок** для документа — это `15-image-kit`;
- 🔴 **PPTX не проверен** (`FORMATS.md` §0) — слайды через `11-presentation-kit`.
