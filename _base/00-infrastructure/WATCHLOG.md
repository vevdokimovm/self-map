   до сторожа. Замерено: КПД 37 % (`SYN-031`). Закрыл батч — следующий **вызов инструмента**.

## §1. Аккаунты и протокол вахты

Репа ведётся с нескольких аккаунтов Claude — **V, J, M, S** — по очереди. У Claude нет общей памяти
между аккаунтами; журнал самодостаточен для любого входящего. Непрерывность/чекпоинты —
`23-session-continuity.md`; слияние разошедшихся линий — `22-merge-protocol.md`.

Приёмка вахты (начиная сессию):
1. Прочитай §0 (где стоим) и §2 (куда идём).
2. Пробеги §4 (грабли) и §5 (правила).
3. **Идёт кампания → прочитай ВСЕ артефакты её прогона** (`PLAN.md`, `README.md`, `SYSTEM-MAP.md`,
   `decisions.md` в `05-infra-synthesis-lab/runs/…`). §0 отвечает «какой следующий шаг», а НЕ
   «что уже сделано» — у многосессионной работы это разные файлы. Пропуск этого пункта уже стоил
   переделанной инвентаризации и чтения закрытой зоны: PIT-072.
4. Работай, обновляя §0 по ходу.
5. Закончил подшаг → §0; нашёл грабли/факт → §4; значимое изменение → §3 + `CHANGELOG.md`;
   сработал триггер разбора → отчёт по `19-reporting-system.md`.

## §2. Направление репы

- **Тема и зачем:** родительская репа системы («базовый класс») — единый источник
  правил, стандартов, протоколов и карта всех реп. Остальные репы наследуют отсюда.
- **Текущий фокус:** довести инфраструктуру до полноты, запушить, начать использовать
  как template для новых реп.
- **Что НЕ входит в репу:** тематический контент (он в тематических репах). Здесь —
  только инфраструктура и правила.

  только диффом множеств «чего не хватало ДО» vs «ПОСЛЕ». Правило: не перезаписывать (класть рядом
  + лог) и обязательный пост-дифф. `53-infrastructure-sync-standard.md` §5 урок 1.
- **2026-08-20** — **фильтр по размеру рвёт логические наборы.** Тесты 6 задач контеста: у 4
  архивы <10 MB, у 2 больше → порог «10 MB в сторону» разорвал набор пополам. Резать по смыслу
  серии, а не по размеру отдельного файла. Там же, урок 2.
- **2026-07-18** — **«temporarily unavailable» на Bash = outage классификатора авто-режима, не кривая
  команда.** `echo`/read-only идут мимо классификатора и работают; сложные команды режутся. Лечится: не
  долбить идентично (≥2–3 фейла → упростить+отложить), backoff/`send_later`, не пере-нарративить. PIT-013 +
  `reports/incidents/bash_classifier_channel_outage_incident.md`.
- **2026-07-18** — **egress-allowlist песочницы Cowork — стена, не обходится кодом изнутри.**
  `api.telegram.org` даёт 403 на CONNECT-тоннель (бот/свой MCP внутри той же VM не помогают); GitHub —
  вообще без коннектора в реестре (видимость приватных реп только косвенно через письма Actions в Gmail).
  Обход — только снаружи песочницы (VPS-поллер) или ждать официальный коннектор. Разобрано в
  `35-mcp-connectors.md` §3.
- **2026-07-18** — **scheduled task ≠ локальный `Cron*`.** Локальные `CronCreate/List/Delete` —
  внутрипроцессный планировщик, умирает с сессией → расписание тихо не сработает. Любое «по расписанию /
  на потом через часы-дни» — только `create_trigger` (MCP claude-code-remote). `34-cowork-scheduled-tasks.md` §2.
- **2026-07-18** — **корреляция на 2–4 аккаунтах почти всегда конфаунд** (кейс «Cowork только на
  proton-аккаунтах»): n=2 на n=2, различаются не только почтой (план/волна раскатки/регион). Причина
  почти наверняка план/rollout-ring, а не почта. Изолировать фактор до вывода — `39` §6, метод `28`.
- **2026-07-05** — GitHub template **не синхронизируется** с потомками (в отличие от
  fork). Template = фабрика скелетов на момент создания, а не живое наследование.
  Разобрано в `09-template-repository.md`.
- **2026-07-05** — тяжёлые файлы остаются в истории git навсегда и качаются при каждом
  клоне, даже после удаления. Дельта-сжатие не берёт JPEG/MP4/ZIP/docx. Отсюда — не
  пускать тяжёлое в историю вообще. Разобрано в `10-git-reference.md` §2.
- **2026-07-08** — при работе с нескольких аккаунтов параллельные ветки документации
  дают **одинаковые номера разным докам** (при слиянии v1.2.0 встретились три разных
  «09/10»). Сверять по **содержимому**, не по имени/номеру/дате файла: копия кита может
  быть собрана с более раннего снапшота, чем актуальная репа (так было с 01/05/06 —
  в ките не хватало порогов размера v1.1.0). Новым докам номер присваивается в момент
  слияния в base-repo.
- **2026-07-08** — macOS-zip отдаёт имена в NFD («й» = «и»+диакритика) — пути с кириллицей
  могут «не находиться» при точном совпадении строки. Лечится нормализацией в NFC
  (`unicodedata.normalize('NFC', name)`). Плюс мусор `__MACOSX/` и `.DS_Store` — чистить
  до коммита (корневой `.gitignore` уже прикрывает `.DS_Store`).
- **2026-07-09** — `templates/publish.sh` уже обходит известные грабли релиза (закодированы внутри):
  CHANGELOG парсится питоном в `--notes-file` (кириллица/тире не бьётся в shell-пайпе), `git push`/`gh`
  — с ретраями под РФ-TLS-таймауты, существование тега/релиза — по РЕЗУЛЬТАТУ вывода (не по коду
  выхода), `gh release view` — через temp-файл. Детали — `25-versioning-and-releases.md` §4.
- **2026-07-09** — «чистка ≠ долив» (`reports/pitfalls.md` PIT-004): обновление уже существующей репы
  на GitHub — **полной заменой рабочего дерева** (клон → стереть всё кроме `.git` → распаковать →
  `git add -A`), а не распаковкой поверх (иначе переименованные/удалённые файлы остаются, задвоение).
  Ведущую точку у dotfiles не срезать (PIT-003). Скрипт `push_base_repo.sh` в доставке делает это верно.

- **2026-07-09** — грабли zsh (PIT-005): комментарий в строке команды (`cmd  # пояснение`) уходит в
  программу как аргумент, если `interactive_comments` выключен → `analyze.py` падал «нет файла лога: #».
  Фикс: скрипт игнорирует мусорный арг (путь только если реальный файл/`.csv`); в инструкциях — чистые
  copy-paste-блоки без inline-комментариев.

- **2026-07-09** — заливка готового дерева: `git add -A` **уважает `.gitignore`** → файлы молча
  выпадают, репа на GitHub «пустая» (PIT-006). Правило: заливать полное дерево через `git add -A -f`.
  После `unzip` — разворачивать обёртку (PIT-007). После пуша — автопроверка `git ls-tree -r HEAD | wc -l`
  (0/1 = баг). «Пустая репа» ≠ потеря: сперва `git log`/`ls-tree` (PIT-008). Всё это вшито в
  `push_base_repo.sh`/`sync-all.sh`; архивы-бэкапы не удалять несколько дней.

- **2026-07-09** — две новые кодифицированные грабли (детали — `reports/pitfalls.md`):
  **PIT-009** — Info-ZIP пишет кириллические имена как literal `#Uxxxx` при распаковке zip без
  UTF-8 флага (так в v1.4.0 уехал весь кит; чинится декодером + проверкой имён до коммита);
  **PIT-010** — деструктив в multi-line paste-блоках выполняется не там при падении `&&`-строки
  (авария v1.2.0; деструктив — только в скриптах с sanity-check).
