## 0. Главный принцип

**Вопрос «какая нейросеть лучшая» — неправильный.** Правильный: «какой инструмент решает
*вот эту* задачу за приемлемые деньги при моих ограничениях».

Три ограничения, которые определяют выбор чаще, чем качество модели:
1. **Приватность** — уходят ли данные наружу (для медицинских/личных/правозащитных материалов
   это часто решающее);
2. **Модальность** — умеет ли инструмент вообще принимать этот тип данных;
3. **Объём** — разовая задача или поток.

## 2. Клод: честно, что лучше и что хуже

**Сильные стороны:**
- Длинный контекст с сохранением связности — большие документы, длинные разборы;
- аккуратность в следовании сложным инструкциям и протоколам (наши режимы чтения — именно про это);
- работа с файлами и кодом в агентном режиме (Claude Code) — сильная сторона;
- письменный русский — на уровне, редкость среди моделей.

**Слабые стороны / потолки (проверены на этом проекте):**
- **Не слышит аудио, не смотрит видео** — нужен препроцессор;
- **бюджет изображений в разговоре** — массовый визуальный проход мрёт (INV-VISION), сканы читаются
  частями по ~55 страниц;
- **нет индикатора расхода контекста** в вебе (в Claude Code есть `/context`) — планировать вслепую;
- **генерация изображений отсутствует** — только чтение;
- рукописный текст читает глазами, но **OCR-инструменты кириллическую скоропись не берут** —
  качество упирается в разрешение носителя.

**Где Клод объективно не лучший выбор:** массовая дешёвая обработка потока (китайские API дешевле),
генерация картинок/видео (не умеет), полностью офлайн (Ollama), распознавание речи (Whisper).

## 3. Локально против облака

**Ollama** — запуск открытых моделей на своей машине.

- ✅ Данные не уходят никуда. Для медицинских, личных и правозащитных материалов это решающий довод.
- ✅ Бесплатно и без лимитов.
- ❌ Качество ниже топовых облачных; тяжёлые модели требуют памяти.
- **Практическое правило:** локально — то, что нельзя отдавать наружу и где хватает среднего
  качества (черновая обработка, классификация, извлечение). Облако — то, где нужен максимум.

## 4. Китайские против американских

⚠️ *по состоянию знаний, проверить перед выбором*

- **Китайские** (DeepSeek, Qwen, GLM, Kimi, MiniMax): часто **открытые веса** → можно поднять
  локально; API в разы дешевле; сильны в математике и коде. Минусы: политика данных, цензурные
  фильтры на части тем, документация местами только на китайском.
- **Американские** (Anthropic, OpenAI, Google): дороже, но зрелее экосистема, интеграции,
  предсказуемая политика.
- **Практика:** открытые китайские веса через Ollama — отличный способ получить локальную модель
  приличного уровня бесплатно.

## 5. Что реально бесплатно

| Категория | Бесплатное решение |
|---|---|
| Распознавание речи | Whisper локально — полностью ✅ |
| Локальные модели | Ollama + открытые веса ✅ |
| Агентный IDE | Antigravity — public preview бесплатен ✅ |
| Заметки/знания | Obsidian (локально) ✅ |
| Работа с медиа | ffmpeg ✅ |
| Чаты моделей | Бесплатные тарифы у всех — с лимитами по объёму и доступом к слабым моделям |

**Правило:** бесплатные тарифы чатов режут не столько качество, сколько **объём и доступ к
топовым моделям**. Для разовой задачи хватает; для потока — упрёшься в лимит.

---

## 6. Как выбирать (алгоритм)

1. **Данные чувствительные?** → да: локально (Ollama, Whisper). Нет → дальше.
2. **Модальность?** Аудио/видео → сначала препроцессор в текст.
3. **Разово или потоком?** Разово → любой удобный. Потоком → считать цену за единицу.
4. **Нужен максимум качества или достаточно среднего?** Среднего → дешёвое/локальное.
5. **Есть ли уже подключённый инструмент?** — Gamma/Canva для презентаций у тебя **уже есть**,
   не ищи новое.
