# 12 — Кейс academic-portfolio: из архивов — в рабочий инструмент (полный разбор)

> Подробный хронологический разбор боевой кампании по правилам `11-slimming-practicum.md`:
> что было, какие решения принимались и почему, как устроен нейминг-движок, какие
> цифры на выходе. **236 МБ репы + 2.7 ГБ входящих архивов МИФИ → 42 МБ рабочей копии
> (~30 МБ на GitHub)**, 953 переименования, ноль битых ссылок, все deliverables целы.
> Читать в паре с `09`: там — правила, здесь — как они применялись в жизни.

## Исходное состояние

| Проблема | Масштаб |
|---|---|
| Вес репы | 236 МБ (при цели 🟢 ≤50 МБ) + 10 архивов МИФИ на 2.7 ГБ во входящих |
| Бинарники вместо конспектов | 151 docx + 3 pptx, ~40 МБ текстовых PDF, 25 ipynb с output'ами |
| Сканы | тысячи страниц рукописных лекций (PDF/JPG), ~1.5 ГБ в архивах |
| Датасеты | 105 CSV телеметрии «Модели управления АТК», 38.6 МБ |
| Нейминг | кириллица, пробелы, скобки, `№`, NFD-имена: 679 файлов + 274 папки |
| Структура | свалка `misc/` (35 файлов), «Разное», файлы не в своих разделах |
| Документация | README со старыми именами, без инфраструктуры, журнала нет |

## Хронология: три волны

**Волна 1 — вес основной репы (фазы 1–8 из `09`).**
Инвентаризация → механика (мусор, sha256-дубли, пары docx+pdf, очистка ipynb) →
105 CSV → `dataset-notes.md` (−38.6 МБ) → docx/pptx/текстовые PDF → `.md`-конспекты
(семестры 03–08: 122 docx + 2 pptx + 27 PDF; 135 → 11 МБ) → сканы → описи →
3 презентации-deliverable сжаты Ghostscript `/ebook` (7 → 3.5 МБ). Итог волны: 47 МБ.

**Волна 2 — ingest архивов МИФИ.**
10 архивов (2.7 ГБ) обработаны **по одному** (диск конечен): распаковка с CP437-фиксом
и NFC → роутинг по предметам → sha256-дедуп → классификация PDF (текст/скан) →
свои работы полным текстом, чужие учебники (>200 КБ извлечённого) — стабами,
рукописи — описями → README по предметам. Итог: раздел `10-mephi-2019-2022` —
**3.9 МБ, 21 предмет**, при этом ни один смысловой материал (билеты, конспекты,
контрольные, код) не потерян.

**Волна 3 — превращение в инструмент (фазы 9–13 из `09`).**
Кит `base-repo` интегрирован → `misc` разнесён по содержимому → нейминг-ревизия →
починка ссылок → регенерация README → журнал → приёмка. Подробности ниже.

## Волна 3 в деталях

### 1. Интеграция инфраструктуры

В корень репы легли `00-infrastructure/` (документы 01–08 + журнал) и `templates/`
из кита. Конфликт: раздел `00-school` занимал зарезервированный префикс `00-` —
переехал в `11-school` (нумерация 01–10 не тронута → минимум починки ссылок).
`repos-map.md` заменён свежей версией кита (с `base-repo`) + возвращена правка про
МИФИ-период. `.gitignore` — шаблон кита + Python-блок (в репе есть учебный код).
`WATCHLOG.md` пересобран по шаблону `03` (§0–§5) и переехал в `00-infrastructure/`.

### 2. Разноска misc — предмет определяется по содержимому

Свалка из 35 файлов. Ключевые определения «по нутру», не по имени:

| Файл | Улика в содержимом | Куда |
|---|---|---|
| «Лекция 13 (Костин)» | формула `x'(t) = A(t)x(t)`, n×n матрица | ОДУ (и это скан с OCR-мусором → опись) |
| «определения-на-коллок» | mojibake; после починки latin-1→cp1251: `lim xn = a` | матанализ |
| «Практика 1/2» | «Создайте конвейер…» — Unix-пайпы | программирование |
| «проскуряков» | известный задачник по линалу | линейная алгебра |
| «аааа.md» | статья с Math-Net.Ru (Таратин, Воробьёв) | project-practice, смысловое имя |
| «ПП — Идентификация по сетчатке» + код | ПП = проектная практика | project-practice/code |

Попутно: `РСПЗ.md`+`рспз.md` — один документ в двух извлечениях → слиты; мотивписьмо
«Новый уровень» — внеучебка, лежало в семестре → `09-extracurricular` («своё в своей зоне»).

### 3. Нейминг-движок (`rename_map.py` + `apply_rename.py`)

Архитектура — каскад из `09` §«Нейминг-ревизия», в цифрах этого кейса:

| Слой | Объём | Пример |
|---|---|---|
| KEEP-список | ~8 имён | `Dockerfile`, `WATCHLOG.md` — не трогаем |
| Точный словарь файлов | **446 правил** | `ВКР_2026_АСУ_ЕвдокимовВМ_БИВТ-22-СП-1.pdf → bachelor-thesis-finpilot-2026-evdokimov.pdf` |
| Точный словарь папок | ~110 правил | `Модели управления АТК → transport-complex-control-models` |
| Паттерны семейств | 3 regex | `Лаба(\d+).sql → lab-N.sql` (закрыл 50 SQL), даты лекций, `N.JPG` → зеро-пад |
| Механика латиницы | автоматом | `ML1.1 Linear Regression (ALL).ipynb → ml1-1-linear-regression-all.ipynb` |
| Транслит-фоллбэк | 51 срабатывание | почти все — SQL-лабы, легли в паттерн идеально; 1 кривое имя поправлено руками |

Применение: сначала файлы, потом папки снизу вверх; коллизии в одной папке — суффикс
`-2`; **каждая пара `старое → новое` — в JSON-лог**. Политика кода: `.py/.cpp/.pas`
переименованы только при не-ASCII, в snake_case (`Сортировка_выбором.py →
selection_sort.py`); интерлинкованные HTML (сайт, книга) не тронуты.

Пост-фиксы после прогона: 6 папок с NFD-символами (ĭ, ë) не совпали с NFC-ключами
словаря — пойманы повторным обходом с `unicodedata.normalize('NFC', name)`;
`^` и `=` в трёх именах добиты руками. Итог: **679 файлов + 274 папки**, финальный
скан кириллицы/NFD/спецсимволов — чисто.

### 4. Починка ссылок по логу

Из лога собраны карты: 584 файловых и 270 папочных замен. Имена файлов (с расширением)
заменялись по всему тексту; папки — только в path-контексте (`старое/`, `](старое)`),
чтобы не задеть прозу; `.ipynb` правились через `json` (кириллица в `\u`-эскейпах).
Затронуто 60 файлов, включая код, читающий данные (`Москва_2021.txt → moscow-2021.txt`
и в `.py`, и на диске). Затем линк-чекер по всем `.md`: 75 ссылок на картинки из бывших
docx (сами картинки не сохранялись) нейтрализованы в пометку
«*(рис. из оригинала — не сохранён при slimming)*». Финал: **0 битых ссылок**.

### 5. Регенерация README

21 предметный README МИФИ собран **из файловой системы** (новые имена гарантированно
верны): материалы классифицируются по маркерам в содержимом — «Полный текст не
хранится» / «Внешний учебник» → *учебник-стаб*; «только опись» / «OCR-слой нечитаем» →
*скан-заметка*; остальное → *проработанный материал*. Исторические таблицы-описи
удалённых сканов **перенесены из старых README как есть** (это контент, русский
допустим). Раздел `10-mephi/README.md` — таблица предметов со счётчиками. Корневой
README: карта дополнена `00-infrastructure` / `11-school` / `templates`, highlights
указывают на новые имена deliverables.

### 6. Журнал по протоколу

`WATCHLOG.md` вёлся **по ходу** (сессии реально обрывались — резюм-поинт §0 каждый раз
позволял продолжить с точного места без перечитывания репы). Урок: правки журнала
скриптом делать **разбиением по заголовкам секций**, а не многострочным regex —
хрупкий regex дважды молча не совпал, и правка терялась (грабля №11 в `09`).
