# 08 — Автоматические триггеры и советы

> Таблица «событие → действие»: как только случается левое, делаешь правое. Чтобы
> поддержание репы шло на автопилоте, а не «когда-нибудь разгребу». Многие триггеры
> может отрабатывать Claude сам, если попросить или держать этот файл в knowledge проекта.

## Периодическая ревизия (раз в период)

Прогони репу по чек-листу правил чистоты (`05`):
1. Актуальность — есть устаревшее? Обнови/удали.
2. Дубли — есть повторы? Слей.
3. Обобщённость — есть сырой копипаст вместо тезисов? Сожми.
4. Лёгкость — есть тяжёлое/генерируемое? Вынеси/удали.
5. Чистота зоны — есть чужое? Перенеси.

Удобно делать в Cowork: даёшь репу + правила `05`/`06`, просишь пройтись и предложить
правки. Claude находит дубли/тяжёлое, ты подтверждаешь — и коммитишь частями.

## Совет по ритму

Не «однажды наведу порядок», а **маленькими шагами по триггеру**. Каждый заход
оставляет репу чуть чище, чем была. Журнал (`04`) держит преемственность между заходами.
