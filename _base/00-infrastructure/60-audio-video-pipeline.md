# 60. Аудио и видео: как сделать их читаемыми

> Проблема: ассистент **не слышит звук и не смотрит видео**. Текст читает, картинки видит,
> аудио/видео — нет. Значит нужен препроцессор: превратить медиа в текст и кадры, и уже их
> подавать на анализ.
> Практический повод: архивы ДСО (.ogg/.mp3), лекции, записи встреч.

> **Происхождение.** Методичка написана в `character-a-analysis` и повышена в базу

## 1. Схема

```
аудио (.ogg/.mp3/.m4a) ──┐
                         ├─→ [Whisper] → .txt/.srt → анализ (это уже обычный текст)
видео (.mp4/.mov) ─┬─────┘
                   └─→ [ffmpeg: кадры] → .jpg → визуальный анализ
```

Ключевая мысль: **транскрипт — полноценный источник**. После расшифровки материал попадает под
обычные правила (режим A, дословность, разметка неуверенности `[?]`/`[нрзб]`).

## 2. Whisper — основной инструмент

Открытая модель распознавания речи от OpenAI. Бесплатная, **работает локально** (аудио никуда
не уходит — важно для чувствительных архивов), русский держит хорошо, покрывает 99 языков.
По состоянию на середину 2026 остаётся эталоном по многоязычности.

### Установка (macOS)

```bash
brew install ffmpeg
pip3 install -U openai-whisper --break-system-packages
```

Быстрее и экономнее по памяти — форк **faster-whisper** (те же веса, ~4× скорость):
```bash
pip3 install faster-whisper --break-system-packages
```

Без терминала на Mac — **MacWhisper** (GUI-обёртка, drag-and-drop, платная разово).

### Запуск

```bash
whisper запись.ogg --language ru --model medium --output_format txt
whisper запись.ogg --language ru --model medium --output_format srt   # с таймкодами
```

**Всегда указывай `--language ru`** — автоопределение на плохом звуке промахивается и начинает
«переводить».

### Выбор модели

| Модель | Вес | Качество на русском | Когда |
|---|---|---|---|
| `tiny` / `base` | ~75–150 МБ | слабое | черновая навигация |
| `small` | ~500 МБ | приемлемое | быстрый прогон |
| `medium` | ~1.5 ГБ | **хорошее — рабочий выбор** | обычная задача |
| `large-v3` | ~3 ГБ | лучшее | важные записи, плохой звук |

### Батч-обработка папки

```bash
for f in *.ogg; do
  whisper "$f" --language ru --model medium --output_format txt --output_dir ./txt
done
```

## 3. Видео

```bash
ffmpeg -i video.mp4 -vn -ar 16000 -ac 1 audio.wav     # вытащить дорожку → в Whisper
ffmpeg -i video.mp4 -vf fps=1/30 frames/%03d.jpg      # кадр раз в 30 сек
ffmpeg -i video.mp4 -vf "select='gt(scene,0.4)'" -vsync vfr key/%03d.jpg  # смена сцены
```

Для лекций/скринкастов кадры по смене сцены дают слайды почти без дублей.

## 4. Ограничения — знать заранее

- **Галлюцинации на тишине.** На пустых участках Whisper дописывает фразы (часто титры-шаблоны).
  Лечение: `--condition_on_previous_text False`, вырезать тишину заранее.
- **Не различает говорящих** (нет диаризации). Для диалогов помечать реплики вручную либо брать
  сервис с диаризацией.
- **Имена и термины** коверкает — сверять по списку известных имён.
- **Транскрипт ≠ протокол.** Расшифровка — сырьё; смысловые выводы делаются отдельным проходом.

## 5. Смежное: голосовой ввод

Обратная задача (говорить вместо печатать): **Wispr Flow**, Superwhisper, VoiceInk, Voibe —
обёртки поверх той же технологии, работают системно во всех приложениях. Платные подписочно.
Полезно для длинных промптов и дневниковых записей голосом. Whisper локально решает ту же задачу
бесплатно, но требует терминала.

## 6. Правило хранения

Транскрипты кладутся **рядом с источником** и попадают в пакет проекта; исходное аудио — по
правилу сырья (`57`): наружу, со следом в чеклисте. Транскрипт лёгкий и самодостаточный,
аудио тяжёлое и одноразовое.
