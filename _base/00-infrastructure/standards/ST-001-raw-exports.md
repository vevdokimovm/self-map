## 2. Область

**Применяется к:**
- выгрузкам мессенджеров и сервисов — Telegram, WhatsApp, VK, Notion, Apple Notes, Google Takeout, данные аккаунтов Claude;
- тяжёлым файлам, вынесенным из реп: видео, аудио, большие PDF/PPTX/DOCX, архивы;
- любому файлу, вместо которого в репе лежит служебка.

**Не применяется к:** фотоархиву (`31-media-and-photo-storage.md`), секретам (`94-secret-storage.md`),
файлам, которые целиком живут в git.

## 3. Термины

| термин | значение |
|---|---|
| **сырой экспорт** | выгрузка как её отдал сервис, до любой обработки |
| **оригинал** | файл, который не хранится в git; эталон для служебки |
| **служебка** | `<имя оригинала>.md` в репе: паспорт оригинала и, если сделана, выжимка |
| **выжимка** | извлечённое содержание оригинала: текст, речь, описание кадров (`07-media-to-text-lab/`) |
| **приёмка** | проверка **числами**, что выжимка полна, — до решения об удалении |

## 4. Нормы

| № | норма | чем проверяется |
|---|---|---|
| **СТ-001.1** | Оригиналы и сырые экспорты хранятся **только** в `~/raw-originals/`. | `raw_originals_check.py`: всё вне канона — `stale` или `icloud` |
| **СТ-001.2** | Раскладка: `~/raw-originals/<репа>/<путь, который был в репе>`. Экспорт, у которого ещё нет репы, — `~/raw-originals/_inbox/<источник>-<ГГГГ-ММ-ДД>/`. | вручную; `_inbox` разбирается по `87-file-to-repo-routing.md` |
| **СТ-001.3** | Хранилище **не лежит** в папках, синкаемых облаком (`~/Documents`, `~/Desktop`, iCloud Drive). | `raw_originals_check.py`: статус `icloud` |
| **СТ-001.4** | Каждый оригинал имеет служебку с полями паспорта из §5. | `raw_originals_check.py` читает паспорт; без `sha256` и `оригинал сейчас` служебка не видна проверке — это нарушение |
| **СТ-001.5** | Путь в строке «оригинал сейчас» совпадает с фактическим, а sha256 файла — с паспортом. После любого переноса путь переписывается **в том же шаге**. | `raw_originals_check.py`: `stale` · `changed` · `lost` |
| **СТ-001.6** | 🔴 **Оригинал не удаляется, пока у него нет принятой выжимки.** Служебка с «Содержание не извлечено» — указатель, а не замена. | `raw_originals_check.py`: строка `удалён` при `выжимка` не 🟢 — статус `premature`, гейт FAIL |
| **СТ-001.7** | 🔴 **Удаление после приёмки разрешено, только если источник воспроизводим** (канал существует, выгрузку можно повторить) **или** оригинал признан расходным по `METHOD_IMAGES.md` §9. Иначе оригинал хранится бессрочно. | вручную; основание записывается в служебку |
| **СТ-001.8** | Перенос оригиналов — копия → сверка sha256 каждого файла → только потом удаление источника. | по `53-infrastructure-sync-standard.md`; пост-сверка обязательна |
| **СТ-001.9** | Ранние релизы с архивами, собранными **до** выноса тяжёлого, не удаляются: это единственная копия, которой нет в git. | вручную |

## 6. Порядок

```
1. Приём        экспорт → ~/raw-originals/_inbox/<источник>-<дата>/        СТ-001.2
2. Маршрут      какая репа — по 87                                         → ~/raw-originals/<репа>/…
3. Паспорт      служебка в репе: поля §5, sha256 снят с файла на месте      СТ-001.4
4. Проверка     raw_originals_check.py --repo <репа> → ok                   СТ-001.5
5. Выжимка      лаборатория 07 (/media-to-text), прогон в runs/
6. Приёмка      числами: сообщений = заголовков = блоков текста; минуты речи; кадры
7. Решение      эталон или расходное; воспроизводим ли источник             СТ-001.6, .7
8. Удаление     только при «да» на шаге 7; строка `| удалён |` с основанием — в служебку
```

Шаги 1–4 обязательны сразу. Шаги 5–8 могут ждать сколько угодно, но **шаг 8 не
выполняется без 5–7**.

## 7. Запреты

- Сырой экспорт и оригиналы тяжелее 50 МБ — в git (`06-volume-compression.md`).
- Хранилище оригиналов в `~/Documents`, `~/Desktop`, iCloud Drive.
- Удаление оригинала до принятой выжимки.
- Перенос без переписывания пути в служебке.
- Признание находки по имени файла без совпадения sha256.
- Отключение облачного синка папки, где лежат оригиналы, без предварительного переноса: macOS опустошает локальную папку (случай 15.09.2026).
