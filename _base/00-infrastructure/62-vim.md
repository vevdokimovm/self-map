## 1. Модель: режимы

Главное отличие от привычных редакторов — **режимы**. Клавиша делает разное в зависимости от режима.

| Режим | Что делает | Как войти | Как выйти |
|---|---|---|---|
| **Normal** | Команды и движение (стартовый) | `Esc` | — |
| **Insert** | Ввод текста | `i`, `a`, `o` | `Esc` |
| **Visual** | Выделение | `v`, `V`, `Ctrl+v` | `Esc` |
| **Command** | Команды с двоеточия | `:` | `Enter` / `Esc` |

**Правило новичка:** растерялся — жми `Esc`, ты в Normal. Оттуда всё предсказуемо.

## 2. Минимум для выживания (10 команд)

```
i        вставка перед курсором        :w      сохранить
a        вставка после курсора         :q      выйти
o        новая строка ниже + вставка   :wq     сохранить и выйти
Esc      обратно в Normal              :q!     выйти без сохранения
dd       удалить строку                u       отменить
```

Этого хватает, чтобы отредактировать конфиг и не залипнуть в коммит-сообщении.

## 3. Движение (то, ради чего vim и существует)

```
h j k l     влево вниз вверх вправо      w / b     слово вперёд / назад
0 / $       начало / конец строки        gg / G    начало / конец файла
{ / }       абзац назад / вперёд         Ctrl+d/u  полэкрана вниз / вверх
/текст      поиск вперёд (n — следующее) :42       перейти на строку 42
```

## 4. Грамматика: оператор + объект

Настоящая сила vim — команды **складываются**, как слова в предложении:

```
оператор + количество + объект
   d          2          w      = удалить два слова
```

| Оператор | | Объект | |
|---|---|---|---|
| `d` | удалить | `w` | слово |
| `c` | заменить (удалить + Insert) | `$` | до конца строки |
| `y` | скопировать | `ap` | абзац |
| `>` | сдвинуть вправо | `i"` | внутри кавычек |

Примеры: `ci"` — заменить текст в кавычках · `dap` — удалить абзац · `y5j` — скопировать 5 строк вниз.

**Не заучивай комбинации — выучи операторы и объекты, комбинации соберутся сами.**

## 5. Минимальный `~/.vimrc`

```vim
set number relativenumber   " номера строк, относительные — для прыжков вида 5j
set expandtab tabstop=4 shiftwidth=4
set ignorecase smartcase    " регистронезависимый поиск, кроме запроса с заглавными
set incsearch hlsearch
set scrolloff=5
set clipboard=unnamed       " общий буфер с системой (macOS)
syntax on
filetype plugin indent on
set encoding=utf-8
nnoremap <silent> <Esc><Esc> :nohlsearch<CR>
```

## 6. План освоения (не всё сразу)

1. **Неделя 1** — только выживание (раздел 2) + `hjkl`. Цель: не бояться.
2. **Неделя 2** — движение (раздел 3). Цель: перестать пользоваться стрелками.
3. **Неделя 3** — грамматика (раздел 4). Цель: перестать удалять по символу.
4. **Дальше** — по потребности: макросы `q`, регистры, `:%s/старое/новое/g`.

Встроенный тренажёр: `vimtutor` в терминале, 30 минут, покрывает пункты 1–3.

## 7. Где это пригодится сразу

- `git commit` без `-m` открывает редактор — это vim;
- правка конфигов на сервере/в контейнере, где нет GUI;
- быстрая правка одного файла без запуска тяжёлой IDE;
- в PyCharm есть плагин **IdeaVim** — те же движения внутри привычной среды, хороший мост.
