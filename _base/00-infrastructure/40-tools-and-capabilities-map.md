## 2. Субагенты и workflow (делегирование) — коротко

Два способа увести работу «вбок», чтобы не жечь главный контекст и идти параллельно:

- **`Agent`** — запустить одного субагента под задачу. Возвращает только итог (не свой мусор). Типы:
  `Explore` (быстрый поиск по коду), `Plan` (архитектор плана), `general-purpose`, `claude-code-guide`
  и др. Бери, когда ответ требует прочитать много файлов, а тебе нужен вывод, а не простыня.
- **`Workflow`** — детерминированная оркестрация **многих** агентов (циклы, fan-out, verify). Для
  масштаба, который в один контекст не влезает: аудит всей репы, миграция по всем файлам, ресёрч с
  проверкой. Потолки (одновременность, 1000 агентов, 4096 элементов) — `39` §2.

> Под меня: массовая ревизия repos-map, сверка WATCHLOG по всем репам, аудит FINPILOT по многим файлам —
> кандидаты в `Workflow`. Точечный поиск «где определён класс X» — `Agent`/`Explore`. **Внимание:**
> Workflow может поднять десятки агентов и сжечь много токенов — только по явному запросу.

## 3. Две файловые системы (не смешивать)

Критично для Cowork в облаке: файлы живут в **двух разных местах**.

| Где | Как дотянуться | Для чего |
|---|---|---|
| **Облачная песочница** (рабочий стол Claude) | `Bash`, `Read/Write/Edit` | Вся обработка, сборка, промежуточные файлы |
| **Компьютер владельца** | `mcp__remote-devices__*` (когда открыт десктоп) | Исходники из твоих папок и запись результата назад |

Файл, записанный одним, **не виден** другому — переносить явно (стейджинг). Типовой поток: взять файл с
твоей машины → обработать в песочнице → отдать (`SendUserFile`) и при просьбе записать назад. Шелл
работает **только** в облаке (мост — не удалённый терминал). Детали доставки файлов — `15` §14.

## 6. Чек-лист «какой инструмент под задачу»

1. Нужен файл-результат? → `Write` + `SendUserFile` (сохранить — `create_artifact`, `38`).
2. Прочитать много кода, нужен вывод? → `Agent`/`Explore` (§2).
3. Масштаб, не влезающий в контекст? → `Workflow` (только по запросу).
4. Повторяется по времени? → scheduled task (`34`).
5. Нужен внешний сервис? → коннектор (`35`).
6. Повторяю сценарий руками? → скилл (`37`); целую роль → плагин (`36`).
7. Файл на моей машине? → мост `remote-devices` (§3).
