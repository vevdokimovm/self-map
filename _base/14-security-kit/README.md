резервные копии его данных.

## 🔴 Главное, что нашлось сразу

**Резервных копий не существует ни одной** — при том что SSD выработал 108 %
гарантийного ресурса записи и **распаян на плате**. Это не тема кита,
а срочная задача: `mission-control/TASKS.md`, разбор —
`12-workstation-kit/reports/ssd-and-battery-health-2026-09-02.md` §5а.

Безопасность без резервной копии — защита содержимого сейфа, у которого
не проверено дно.
