# Отпечаток браузера: парадокс уникальности

**Исследование 02.09.2026.** Повод: в тир-листе браузеров «Firefox (Hardened)»
стоит высоко по приватности. Подозрение — настройка ради приватности может
делать отпечаток **узнаваемее**.

---

## §0. Парадокс подтверждён — и сформулирован автором первого исследования

Питер Экерсли описал его сам в работе 2010 года: **редкая защитная мера делает
пользователя заметнее, если ею пользуется мало людей.**

> **Решение — не «случайность», а «одинаковость».** Не подменять признак
> случайным значением, а свести всех пользователей к малому числу
> неотличимых групп.

Это явный принцип, записанный в документации Tor Project:

> *«Tor Browser does not let users select which OS they appear to be.
> This is intentional: any option to choose would only make users more unique
> and thus easier to fingerprint. The small set of standardized options is key
> to keeping users blended together.»*

🔴 Отсюда прямое следствие для владельца: **самостоятельная настройка Firefox
«под приватность» работает против цели**, если только вы не воспроизводите
в точности чей-то массовый профиль.

---

## §1. Сколько бит даёт каждый признак

**Panopticlick / Eckersley, PETS 2010**, выборка 470 161 браузер:

| Канал | Энтропия, бит |
|---|---:|
| список плагинов | **15.4** |
| список шрифтов | 13.9 |
| User-Agent | 10.0 |
| HTTP Accept-заголовки | 6.09 |
| разрешение экрана + глубина цвета | 4.83 |
| часовой пояс | 3.04 |
| включены ли куки | 0.353 |
| **весь отпечаток вместе** | **≥18.1** — один из 286 777 |

**83.6 % браузеров были мгновенно уникальны.** С Flash и Java — **94.2 %**.

**Арифметика «сколько нужно»:** чтобы выделить одного из миллиона, хватает
20 бит; из восьми миллиардов — 33. **Восемнадцати бит уже достаточно
для однозначной идентификации внутри аудитории почти любого сайта.**

---

## §2. 🔴 Контр-результат: уникальность со временем УПАЛА

**Gómez-Boix et al., WWW 2018**, выборка **2 067 942 отпечатка** с одного
из топ-15 французских сайтов:

> Дословно: *«the percentage of unique fingerprints in our dataset is much
> lower than what was reported in the past: **only 33.6 % of fingerprints
> are unique** by opposition to over 80 % in previous studies... the removal
> of plugins brings down substantively the rate of unique desktop machines»*

| Работа | Год | Доля уникальных |
|---|---|---:|
| Panopticlick | 2010 | 83.6 % |
| AmIUnique | 2016 | 90 % desktop / 81 % mobile |
| **Gómez-Boix** | **2018** | **33.6 %** |

🔴 **Это не опровержение парадокса, а другое объяснение.** Падение вызвано
не защитными мерами, а **естественной эволюцией веба**: ушли Flash и Java,
а с ними — самый жирный источник энтропии (15.4 бита на плагины).

⚠️ И разница в природе выборки: AmIUnique собирал данные на **нишевом сайте
про приватность**, Gómez-Boix — на массовом коммерческом. Цифры выглядят
взаимоисключающими без этого контекста.

**Отдельно про мобильные:** у них нет ни плагинов, ни шрифтов, но **81 %
уникальны** — за счёт очень «богатых» User-Agent. Мобильный UA в **пять раз**
различительнее десктопного; примерно **каждый четвёртый смартфон узнаваем
по одному только UA**.

## §3. Что делает `privacy.resistFingerprinting`

Из документации Mullvad Browser (обновлена 13.01.2026), где RFP используется
как есть из Firefox:

- часовой пояс отдаётся как **UTC**;
- доступны не все установленные шрифты;
- окно округляется до фиксированных размеров (**letterboxing**);
- браузер сообщает **обобщённую** версию и ОС;
- маскируются раскладка клавиатуры, язык, возможности камеры и микрофона;
- 🔴 **canvas отдаёт рандомизированные данные**, а не белый экран —
  распространённое представление неверно;
- отключены WebSpeech, gamepad, сенсоры, performance API;
- WebGL `readPixel` отключён полностью.

**Letterboxing — точный механизм:** окно контента округляется до кратного
**200×100 px**. При изменении размера добавляются серые поля, чтобы viewport
попадал в один из немногих «бакетов». Технику разработала Mozilla, представлена
в 2019 году.

⚠️ **Детектируемость самого факта включения RFP подтвердить не удалось** —
страницы Mozilla отдают антибот-защиту вместо контента. Это зафиксированная
неудача поиска, а не факт отсутствия данных.

## §4. uBlock Origin: делает ли отпечаток уникальнее

⚠️ **Прямого ответа получить не удалось** — работы про детектирование
расширений (Sjösten, XHOUND) не добыты, поиск был исчерпан.

🔴 **Но есть косвенный аргумент, и он сильный:** сам Mullvad Browser ставит
uBlock Origin **всем пользователям по умолчанию**, вместе с NoScript.

> По логике парадокса это снимает проблему: **если расширение стоит
> у всех — оно не выделяет никого.** Отличие от случая «пользователь Chrome
> ставит uBO поверх дефолтного профиля», где отпечаток расширения
> действительно может выделяться.

---

## §5. Mullvad Browser — что ломается без сети Tor

Общее с Tor Browser: тот же движок, RFP, letterboxing, уровни безопасности,
шрифтовой пакет, отключённый WebGL `readPixel`.

🔴 **Отличия, которые надо знать:**

- **сеть Tor не встроена** — IP браузером не анонимизируется, нужен отдельный VPN;
- **WebRTC включён** (в Tor Browser это известный вектор утечки IP);
- **Web Audio API включён** — нужен для WebRTC, но это известный канал
  аудио-отпечатка;
- защита от утечки личности между вкладками **отключена по умолчанию**
  (в Tor Browser включена).

## §6. Практический вывод для владельца

**Модель угроз — обычная приватность частного лица, не таргетированная слежка.**

| Что | Стоит ли |
|---|---|
| настраивать Firefox «под приватность» вручную | 🔴 **нет** — работает против цели (§0) |
| ставить uBlock Origin | 🟢 да — массовое расширение, не выделяет |
| Mullvad Browser для чувствительного | 🟢 да, **но только с VPN** |
| гоняться за canvas-отпечатком | 🟡 переоценено — см. ниже |

⚠️ **Что важнее отпечатка — проверить не удалось.** Вопрос «что рекламная
индустрия реально использует в 2026: отпечаток, куки, вход в аккаунт или IP»
остался без ответа: поиск был исчерпан.

Но из механики §2 следует косвенное: доля уникальных отпечатков упала
до трети, значит отпечаток **сам по себе** уже не даёт надёжной
идентификации на массовой аудитории. А вход в аккаунт даёт всегда.

## §7. Что осталось неизвестным

1. **детектируется ли факт включения RFP** — страницы Mozilla под антиботом;
2. **прирост энтропии от uBlock Origin** — работы не добыты;
3. **отличие Firefox FPP от RFP** на 2026 — не подтверждено ни одним источником;
4. **доля уникальных среди пользователей Tor Browser** — количественной
   оценки не нашлось нигде;
5. **энтропия AudioContext, hardwareConcurrency, deviceMemory** — ни одна
   из трёх основных работ их не измеряет: это более поздние API;
6. **раздельные проценты desktop/mobile у Gómez-Boix** — полный текст
   заблокирован, доступен только реферат.

**Ограничение метода:** `WebSearch` был исчерпан на всю сессию (400 из 400).
Работал только прямой доступ по известным адресам; часть площадок отдаёт
антибот-защиту. Обход шёл через веб-архив и Semantic Scholar.
