# 15. Кит изображений — фото, картинки, схемы, гифки

**Заведён 14.09.2026** по требованию владельца: *«раздели два кита. ты просто
в один кит называнный конкретно презентаций запихнул кучу разных сущностей…
картинки это фундамент изображения»*.

**Почему отдельно.** Изображения жили в `11-presentation-kit/DIAGRAMS.md`,
и владелец, искавший «кит картинок», его не нашёл: название говорило
о презентациях. Картинка — самостоятельная единица, слайд и документ её
только используют. Вход одной командой — скилл [`/image`](../.claude/skills/image/SKILL.md).

---

## §0. 🔴 Основной путь — решение владельца 14.09.2026

> Дословно: *«давай кит картинок будет генерить или svg ты сам как пример
> и давать точный промпт для гемини. и я просто этот промпт вставлять туда
> и генерить картинку»*.

**Почему так.** Модель растр не рисует — только текст и код. Подписка
владельца Google AI Pro даёт генерацию в приложении Gemini (Nano Banana,
до 100 в день), но **не API**: API оплачивается отдельно, без бесплатного
лимита на картинки. Gamma — 70 кредитов за картинку. Значит генерирует
владелец в Gemini, а вахта делает всё остальное.

| Шаг | Кто | Что |
|---|---|---|
| 1 | вахта | **SVG-набросок композиции** — где объект, горизонт, свет, пропорции; рендер в PNG, просмотр глазами |
| 2 | вахта | **точный промпт для Gemini** по шаблону §0а — в блоке кода, чтобы копировался целиком |
| 3 | владелец | вставляет промпт в Gemini (при желании прикладывает набросок как референс), генерирует, сохраняет в `~/Downloads` |
| 4 | вахта | забирает файл, **смотрит глазами**, сверяет с задачей, ужимает, кладёт в репу предмета; рядом `<имя>.prompt.md` с промптом |

🔴 **Если задача решается SVG целиком** (схема, иконка, подписи, инфографика) —
шаги 2–3 не нужны, картинка отдаётся сразу (`DIAGRAMS.md` §5а). Промпт
для Gemini — только там, где нужен фотореализм или живая иллюстрация.

🔴 **Не выдавать набросок за результат.** SVG на шаге 1 — схема композиции,
а не картинка; подписывать его «набросок».

### §0а. Шаблон промпта для Gemini

Промпт — **на английском** (генератор точнее понимает), шесть частей в одном абзаце:

```
[Тип]: A photorealistic photo / A flat vector illustration / A watercolor painting of
[Объект]: <что в кадре, конкретно: материал, цвет, количество>,
[Сцена]: <где, что вокруг, фон>,
[Свет и время]: <golden hour / overcast / soft studio light>,
[Камера и композиция]: <wide shot / close-up, eye level, subject on the left third, 35mm lens, shallow depth of field>,
[Стиль и ограничения]: <muted colors, no text, no watermark, no people>. Aspect ratio 16:9.
```

**Правила промпта:**
- **конкретика вместо оценок**: «red wooden house with white window frames»,
  а не «beautiful house»;
- **композиция словами из наброска**: «subject on the left third», «horizon
  at the lower third» — набросок и промпт обязаны совпадать;
- 🔴 **`no text` всегда**, если текст не нужен: генератор дорисует
  псевдобуквы. Нужен текст — накладывается потом SVG-слоем, не генерацией;
- **соотношение сторон — последней фразой**: 16:9 слайд/баннер, 1:1 соцсети,
  4:5 портрет, 9:16 сторис, A4 → 3:4;
- для правки готовой картинки — отдельным сообщением в том же чате Gemini:
  «keep everything, change only <что>».

**Образец** — [`examples/fjord.prompt.md`](examples/fjord.prompt.md) и
набросок [`examples/fjord-sketch.svg`](examples/fjord-sketch.svg).

Был прав: проверка запуском нашла рабочий путь.

| | |
|---|---|

**Когда брать:** нужна картинка без участия владельца и без сети — иллюстрация к заметке,
фон, черновик. Фотореализм и точность сюжета — по-прежнему Gemini (§0).

**Ещё установлен DiffusionBee** (`brew install --cask diffusionbee`, Intel-сборка 2.5.3) —
приложение с окном для владельца; при первом запуске качает свою модель. Скорость не замерена.

### §0г. Ресерч 14.09.2026 — что он сказал и где ошибся

Ресерч 14.09.2026

[`reports/research/image-generation-intel-mac-2026-09-14.md`](../reports/research/image-generation-intel-mac-2026-09-14.md):
на этом маке (Intel i5-8259U, 8 ГБ) хорошего локального пути нет — мак-приложения
и Core ML только под Apple Silicon, PyTorch/OpenVINO/onnxruntime перестали собираться
под Intel. Бесплатная автоматизация из терминала — **Cloudflare Workers AI** (FLUX.1 schnell,
10 000 нейронов в день, VPN). Офлайн — stable-diffusion.cpp или FastSD CPU старого релиза,
качество «набросок». Основной путь остаётся Gemini.
🔴 **Оценка ресерча «10–30 с» разошлась с замером в 4–8 раз** (133 с), а «качество
набросок» — в худшую сторону: вышла годная иллюстрация. Оценка без запуска — не замер.

## §0б. Что чем — по тому, ЕСТЬ ЛИ НА КАРТИНКЕ ТЕКСТ

| Нужно | Чем | Где правила |
|---|---|---|
| **фото, реалистичная сцена, обложка, фон, иллюстрация без текста** | набросок SVG + промпт → владелец генерирует в Gemini (§0) | §0а |
| то же, без владельца и без сети | `bin/gen_image_local.py`, ~2 мин | §0в |
| то же, когда владелец далеко и кредиты есть | Gamma MCP `generate_image` | §1 |
| схема, процесс, архитектура | mermaid → PNG, DOT → SVG | [`DIAGRAMS.md`](DIAGRAMS.md) §1–§4 |
| картинка **с подписями**, иконка, инфографика | SVG-код → `rsvg-convert` → PNG | `DIAGRAMS.md` §5а |
| гифка | SVG-кадры → PNG → `ffmpeg` | `DIAGRAMS.md` §5б |
| видео с озвучкой | `ffmpeg` + `say` | `DIAGRAMS.md` §5в |

🔴 **Граница проходит по тексту.** Генератор рисует похожее на буквы,
а не буквы, и повторяемости нет: тот же промпт — другая картинка.
Всё, где важны подписи или точная структура, — кодом.

## §1. Запасной путь: Gamma `generate_image` — проверено запуском 14.09.2026

`DIAGRAMS.md` §5а от 04.09 записал Gamma как «отключён, проверить не удалось».
14.09 MCP подключён, генерация **проверена реальным вызовом**:

| | |
|---|---|
| вызов | `generate_image`, `type="photo"`, `sizePreset="banner"` |
| промпт | фьорд на рассвете, красный деревянный дом, снег, туман |
| ответ | асинхронно: `pending` → `completed` за 2 опроса `get_image_generation_status` |
| результат | **JPG 2752 × 1536**, 651 КБ, ссылка на `cdn.gamma.app` |
| качество | 🟢 фотореализм, просмотрен глазами, сюжет промпта выполнен целиком |
| образец | [`examples/gamma-photo-fjord.jpg`](examples/gamma-photo-fjord.jpg) — ужат до 1024 px, 74 КБ |
| 🔴 **цена** | **70 кредитов за картинку, после вызова осталось 64** |

🔴 **Кредиты — главное ограничение, а не качество.** При остатке 64 следующая
картинка не пройдёт. Перед генерацией: сказать владельцу цену и остаток,
а не тратить молча — кредиты его, и они конечны.

### Параметры

| Параметр | Значения |
|---|---|
| `type` | `photo` (фотореализм) · `illustration` (по умолчанию) · `scene` · `abstract` |
| `sizePreset` | `social-square` 1:1 · `social-portrait` 4:5 · `story` 9:16 · `banner` / `slide` 16:9 |
| `referenceImages` | до 4 URL — объект или персонаж, который должен появиться; только URL от владельца |

### Порядок

1. Назвать владельцу цену (70) и остаток кредитов.
2. Промпт — на английском, конкретно: сюжет, свет, время суток, фон.
3. `generate_image` **один раз**. 🔴 Повторный вызов для проверки статуса —
   это новая, отдельно оплаченная генерация; статус только через
   `get_image_generation_status`.
4. Скачать по ссылке (`curl -o`), **посмотреть глазами** (Read).
5. Положить в репу предмета, рядом — строка с промптом и параметрами:
   без промпта картинку не повторить и не поправить.
6. Вес: для репы ужать (`sips -Z 1600 -s formatOptions 80`), оригинал —
   только если нужен для печати.

### Чего не проверено

- `referenceImages` и `themeId` — не вызывались;
- как генерация справляется с людьми и лицами — не проверялось;
- Canva `generate-design` как второй источник картинок — не проверялся.

## §2. Чего этот кит НЕ делает

- **не рисует схему растром** — только кодом (`DIAGRAMS.md` §0);
- **не тратит кредиты без слова владельцу**;
- **не выдаёт сгенерированное фото за настоящее** — в документах, где это
  важно (юридические, учебные), подписывать «сгенерировано».
