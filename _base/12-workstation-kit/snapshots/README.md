# snapshots — снимки состояния машины во времени

Не журнал и не отчёт: **снимки на дату**, которые сравнивают между собой.
Пишутся `bin/inventory.py` и разбором демонов.

| Файл | Что зафиксировано |
|---|---|
| `2026-09-02.json` | снимок установленных приложений с версиями |
| `daemons-baseline.json` | 🔴 **метка**: демоны после отключения `optimize-storage` — точка отсчёта |
| `daemons-2026-09-02T2050.json` | тот же срез часом позже — для сравнения с меткой |

🔴 **Смысл пары «baseline + повторный срез».** Одиночный снимок отвечает
«что стоит сейчас» — на это и `ls /Applications` ответит. Пара отвечает
на другое: **программа установилась сама** или **нужное пропало при чистке**.
Без второго снимка первый бесполезен.

**Файлы не удаляются:** снимок, которого нет, невозможно сравнить задним
числом. Объявлены в `12-workstation-kit/.runtime-writes` — в отпечаток канона
не входят, потому что система пишет их о собственной работе
(`00-infrastructure/94` §1).
