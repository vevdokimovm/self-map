# `/document` — документы из Markdown

> **Решение владельца 14.09.2026:** *«разнеси в несколько по смысловым точкам»*.
> Документы вынесены из кита презентаций в `16-document-kit`.

## 🔴 Что НЕ делает

- **не пересказывает кит** — правила в `16-document-kit/README.md` и `FORMATS.md` (`PIT-G`);
- **не пишет содержание за автора**;
- **не делает слайдов и картинок** — `/presentation`, `/image`.

## §0. Формат — по тому, кто читает

| Кто читает | Формат |
|---|---|
| суд, чиновник, комиссия, печать | PDF |
| человек будет править | DOCX |
| читалка, телефон, методичка длинная | EPUB |
| числа, которые считают дальше | XLSX (из markdown-таблицы) |
| показать ссылкой | Artifact, не файл |

## §1. Порядок

1. Исходник `.md` в репе предмета.
2. `python3 scripts/make_document.py src.md --to <формат> --out <путь в репе>`.
3. 🔴 **Посмотреть результат глазами** (Read) до отдачи.
4. Тяжёлый PDF — сжать `gs /ebook` и посмотреть снова: сжатие портит мелкий шрифт.
5. Результат рядом с исходником в репе (`FORMATS.md` §4а).

**Связки:** `16-document-kit/README.md` · `FORMATS.md` · `/presentation` · `/image`.
