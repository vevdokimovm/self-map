# `/image` — изображения: фото, картинки, схемы, гифки

> **Владелец 14.09.2026:** *«картинки просто обычные фотки генерить jpg jpeg png…
> раздели два кита… картинки это фундамент изображения»*.

## 🔴 Первым — что умеет сама модель, а что нет

**Растр модель не рисует.** Она читает картинки, но не выдаёт пикселей.
Всё, что раньше «рисовалось» (`pipeline.png`, `progress.gif`), — это **код**
(SVG), отрендеренный локальной программой. Фото — только внешним генератором.

| Источник | Что даёт | Цена |
|---|---|---|
| **Gemini у владельца** (подписка AI Pro) | 🟢 фото, иллюстрации — по промпту вахты | в подписке, до 100 в день |
| **Локально** `15-image-kit/bin/gen_image_local.py` | 🟢 иллюстрация 512 px, SD-Turbo — замер 15.09: 133 с | бесплатно, офлайн; 🔴 грузит все 4 ядра |
| **Gamma `generate_image`** | 🟢 фото, JPG до 2752 px — проверено 14.09, запасной | 🔴 **70 кредитов за картинку** |
| **SVG-код → `rsvg-convert`** | схемы, иконки, инфографика, точный текст | бесплатно, локально |
| mermaid / DOT | диаграммы | бесплатно |
| Canva `generate-design` | дизайн-макеты | не проверено |

## §0. Развилка — есть ли на картинке текст или точная структура

- **Да** (схема, подписи, иконка, инфографика) → кодом, §2, отдать сразу.
- **Нет** (фото, сцена, фон, обложка, живая иллюстрация) → §1: набросок +
  промпт для Gemini. 🔴 **Это основной путь, решение владельца 14.09.2026.**

## §1. Фото и иллюстрации — набросок + промпт, генерирует владелец в Gemini

> Владелец: *«давай кит картинок будет генерить или svg ты сам как пример
> и давать точный промпт для гемини. и я просто этот промпт вставлять туда»*.

1. **SVG-набросок композиции** → `rsvg-convert` → PNG → **посмотреть глазами**.
   Подписать «набросок», это не результат.
2. **Промпт по шаблону** `15-image-kit/README.md` §0а — английский, шесть частей
   (тип · объект · сцена · свет · композиция · ограничения + aspect ratio),
   `no text` всегда, когда текст не нужен. Отдать **блоком кода** —
   владелец копирует целиком.
3. Сказать строкой: вставить в Gemini, набросок можно приложить как референс,
   готовое сохранить в `~/Downloads`.
4. Когда файл пришёл: **Read, посмотреть глазами**, сверить с задачей,
   ужать (`sips -Z 1600 -s formatOptions 80`), положить в репу предмета,
   рядом `<имя>.prompt.md` с промптом. Не то вышло — дать правку промптом
   «keep everything, change only …».

Образец: `15-image-kit/examples/fjord.prompt.md` + `fjord-sketch.svg`.

**Без владельца** — `python3 15-image-kit/bin/gen_image_local.py "prompt" --out x.png`
(~2 мин, спросить, не играет ли он). **Запасной** — Gamma `generate_image`, только со словом
владельца: 🔴 70 кредитов за картинку.

## §2. Порядок для картинки кодом

1. Написать SVG / mermaid / DOT.
2. Отрендерить (`rsvg-convert -w 1200 x.svg -o x.png`).
3. 🔴 **Посмотреть PNG глазами** — ошибка в SVG выглядит валидным XML
   (стрелка без наконечника, `DIAGRAMS.md` §5а).
4. Исходник рядом с PNG.
