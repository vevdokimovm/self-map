# `/presentation` — слайды

> **Заказ владельца 14.09.2026:** *«давай сделаем и агента скилл заодно»*,
> затем: *«раздели два кита… картинки это фундамент изображения»*.
> Изображения вынесены в `15-image-kit` и скилл `/image`; здесь — то,
> что их **использует**: слайды. Документы — `16-document-kit`, скилл `/document`.

## 🔴 Что этот скилл НЕ делает

- **не пересказывает кит** — правила в `11-presentation-kit/README.md`; копия разошлась бы с оригиналом (`PIT-G`);
- **не пишет содержание за автора** — форма из кита, суть от владельца;
- **не делает картинок и документов** — это `/image` и `/document`.

Отдельного агента нет намеренно: агент не виден в меню `/` и несёт свой
полный контекст — дороже скилла при той же работе.

## §0. Первый вопрос — чем это будут смотреть

| Кто смотрит | Что отдавать |
|---|---|
| комиссия, защита | PDF (или `.pptx`, если требуют) |
| чиновник, суд, методичка в `legal-knowledge-base` | PDF или DOCX |
| коллега, «глянь» | ссылка — Artifact |
| сам владелец разобраться | документ `.md`, не презентация |

🔴 Если ответ «документ на две страницы» — предложить его вместо слайдов.

## §1. Инструмент

| Задача | Чем | Где правила |
|---|---|---|
| сдать слайды файлом PDF | Gamma/Canva экспорт или `/document` | `16-document-kit` |
| слайды из текста | Gamma MCP `generate` | `README.md` §1–§3 |
| слайды с контролем макета, бренд | Canva MCP | `README.md` §1 |
| одностраничник по ссылке | Artifact | `README.md` §1 |
| картинка, схема, фото на слайд | → `/image`, потом вставить | `15-image-kit` |

## §2. Порядок

1. §0 — кто смотрит.
2. Структура защиты — `README.md` §2 (слайд «ограничения» не пропускать).
3. Собрать.
4. 🔴 **Посмотреть результат глазами** (Read на PDF) до отдачи.
5. Сжатие PDF (`gs /ebook`, `README.md` §4) — и посмотреть снова:
   сжатие портит векторные графики и мелкий шрифт.
6. Положить **в репу предмета**, исходник рядом (`16-document-kit/FORMATS.md` §4а).
