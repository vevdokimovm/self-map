# `/analyst` — сухие числа по своим данным, с честной границей

## Место в связке

Владелец 29.08.2026 предложил цепочку, и она осмысленна:

```
/options   → варианты и цена каждого
/expert    → независимая проверка постановки
/analyst   → числа под каждым вариантом
```

**Разделение простое:** `/research` добывает знание **извне** (рынок, наука),
`/analyst` считает по тому, что **у нас уже записано**. Спутать их — значит
либо гадать вместо расчёта, либо считать по выдуманным данным.

## Что есть чем считать — замер 29.08.2026

| Источник | Записей | Что даёт |
|---|---|---|
| `06-autonomous-mode-kit/runs/auto.log` | **327** батчей | темп работы, простои |
| `scripts/timing.py` | **238** промежутков | сколько занимает батч |
| `reports/releases/LEDGER.tsv` | **279** выпусков | рост объёма во времени |
| `reports/pitfalls.md` | **151** карточка | классы дефектов, покрытие |
| `limits_watch.py` | **132** упора | когда упираемся в лимит |
| `measurements.csv` | 38 строк | расход токенов по сессиям |
| `reports/durations.tsv` | 🔴 **2** записи | замеры конкретных действий — **мало** |

Последняя строка приведена намеренно: **источник, которого не хватает,
называется до расчёта, а не после**.

## 🔴 Пять правил, без которых расчёт вреден

**1. Медиана, а не среднее.** Наши распределения перекошены: один батч
с девятью субагентами перекашивает среднее так, что оно перестаёт описывать
типичный случай. Замер: медиана промежутка **11 минут**, а самый долгий —
**353**. Среднее здесь меряет длину пауз, не длину работы.

**2. Выборка меньше 10 — не статистика, а анекдот.** Называть число можно,
делать вывод — нет. Так `it-base` с тремя замерами дал «медиану 217 минут»,
и это не свойство репы, а три случайных промежутка.

**3. Корреляция не причинность, и это не формальность.** Исследование
29.08 показало: методология DORA — **cross-sectional**, то есть в принципе
не может доказывать причинность, а её выводы читают каузально. Мы в тех же
данных.

**4. Ложная точность опаснее отсутствия числа.** Одно число там, где честна
вилка, — обман: на него опираются как на замер. Пример того же дня: вес базы
считается **вилкой 1,76–2,80 млн токенов**, потому что настоящего
токенизатора нет.

**5. Что не измеряется — называть, а не обходить.** У `flow_metrics.py`
это встроено: он печатает, чего измерить **нельзя** (приток и скорость
обслуживания задач владельца — нет дат), и не печатает выдуманное «время
жизни задачи».

## Что делать

**1. Собрать сырьё** — из таблицы выше, командами, а не по памяти.

**2. Посчитать** — медиана, доли (25/50/75/90), разброс. Тренд — только
если точек больше десяти и они по времени.

**3. Проверить три вещи перед выводом:**
- **сколько точек** — меньше 10 значит «наблюдение», не «закономерность»;
- **не перекошено ли** — сравнить медиану со средним; расходятся вдвое
  значит хвост правит;
- **что могло дать этот результат, кроме названной причины** — назвать
  хотя бы одну альтернативу.

**4. Сформулировать так, чтобы нельзя было переврать:**

> ✅ «Медиана батча — 11 минут (238 замеров, паузы длиннее 6 ч отброшены).
> Это **верхняя** оценка: в промежуток попадают ожидание и вопросы».
>
> ❌ «Батч занимает 11 минут».

**5. Если данных не хватает — сказать это ответом, а не оговоркой в конце.**

## Готовые инструменты — не считать заново руками

```bash
python3 scripts/timing.py                       # длительности, распределение
python3 scripts/flow_metrics.py                 # закон Литтла, что НЕ измеряется
python3 scripts/load_weight.py                  # вес набора в токенах, вилкой
python3 scripts/pitfall_coverage.py             # покрытие ловушек механизмами
python3 06-autonomous-mode-kit/bin/limits_watch.py   # лимиты как данные
python3 reports/experiments/token-consumption/session_metrics.py
```

🔴 **Сначала проверить, нет ли готового инструмента.** Замер 22.08.2026:
четыре прогона агента-замерщика стоили **2,79 млн токенов чтения** — 66 %
всего расхода субагентов за сессию, при том что скрипт даёт те же числа
одним проходом.

## Чего эта скилла НЕ делает

- **не добывает данные извне** — рынок и наука это `/research`;
- **не решает** — числа под вариантами, выбор за владельцем (`/options`);
- 🔴 **не считает того, чего не записано.** Задача без даты заведения
  не даёт времени жизни; действие без замера не даёт длительности.
  «Посчитай, сколько занимает X» при отсутствии замеров X — ответ
  «нечем», а не оценка на глаз;
- **не подтверждает гипотезу владельца.** Если числа против неё —
  сказать это прямо, с выводом команды.
