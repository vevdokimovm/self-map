# `/tokens` — служебный срез сессии

> **Зачем скилла поверх агента.** Субагенты **не появляются в меню `/`** — их вызывает
> модель, не интерфейс. Владелец искал `token-probe` через слеш и не нашёл, потому что
> его там нет по устройству. Эта скилла — вход через слеш к той же работе.

## 🔴 Панели интерфейса — ПЕРВАЯ команда, не последний штрих

> **Требование владельца, 25.08.2026:** *«tokens ВСЕГДА ВСЁ это должно учитываться»*.
> **Найдено 27.08.2026 — этот пункт пропускался вахтой, хотя выполняется одной
> командой.** `panel_probe.py` существует с 25.08.2026 и автоматизирует три из
> четырёх панелей БЕЗ скриншота и без вопроса владельцу. Вахта записывала «панели
> не сняты — нечем снять», ни разу не запустив инструмент. Не повторять.

**Первым действием `/tokens`, ДО `session_metrics.py`, ДО любого вывода:**

```bash
python3 reports/experiments/token-consumption/panel_probe.py
```

Даёт **Status + Stats + Usage** за один вызов, без экрана владельца и без сети
(кроме Usage — тот же `security find-generic-password`, разрешён в `settings.json`).
Только **Config** остаётся частично недоступен локально (некоторые тумблеры
интерфейса не найдены ни в одном файле) — вот этот один пункт, если он нужен для
разбора, спрашивается у владельца одной строкой. Не все четыре панели скриншотом —
**только Config**, и только если он реально нужен для текущего вопроса.

Провал команды (не «спросить» — **выполнить и посмотреть на код возврата**) —
единственное законное основание написать «панель недоступна», и в этом случае
называется точный вывод ошибки, а не «нечем снять» (`71-fail-loud-and-sourcing.md`
§7ж: не пробовал ≠ не работает).

Разбор и запись панельных чисел в `hypothesis.md`/`measurements.csv` — тем же
батчем, не «когда-нибудь потом». Полный перечень полей и прецедент —
`hypothesis.md`, разделы «Панель "What's contributing to usage"…» и
«три из четырёх панелей автоматизированы» (25.08.2026).

## 🔴 Сначала — решить, нужен ли агент вообще

**Замерено 22.08.2026:** четыре прогона `token-probe` стоили **2 792 293 токена чтения** —
**66 % всего расхода субагентов за сессию**. Два последних — по миллиону **за один срез**.
Скрипт даёт те же числа одним проходом без модели.

| Что нужно | Чем брать |
|---|---|
| ходы · контекст · кэш · компакт · бакеты · строка CSV | **`session_metrics.py` напрямую** |
| расход субагентов | одна команда по `projects/<sid>/subagents/**/*.jsonl` |
| сверка с гипотезой, решение «править или оставить» | **вахта**, по выводу скрипта |
| `token-probe` | **только** когда нужен разбор незнакомого, а не пересчёт известного |

> **Проверка перед вызовом агента: существует ли скрипт, дающий то же число?**
> Есть — агент не нужен; суждение вахта вынесет сама.

## Что делать

**1. Запустить агента `token-probe`** — *если предыдущий раздел говорит, что он нужен* — он снимает срез по реальному логу
`~/.claude/projects/**/*.jsonl`: модель · усилие · ходы · контекст (макс, медиана, прирост) ·
кэш и распределение TTL · компакция по маркеру · цена хода по бакетам 25K · субагенты ·
вложения. Возвращает готовую строку для `measurements.csv` и расхождения с `hypothesis.md`.

Аргумент владельца, если он был, передать агенту дословно.

**2. Получив отчёт — записать в лабораторию** (агент этого не делает намеренно):

- строка в `reports/experiments/token-consumption/measurements.csv`;
- новое или изменённое — в `hypothesis.md` §3, **с датой и источником**;
- 🔴 подтверждённые 🟢-строки **не переписывать** без веской причины и без числа.

**3. Закрыть батч**, если правилась база: `revision_check.py` → CLEAN, `VERSION`,
`CHANGELOG`, `WATCHLOG` §0 и §3, `pack_release.py`.

## Чего НЕ делать

- **Не считать самому по логу мимо агента.** Инструмент выверен, у него канарейка;
  ручной счёт по строкам завышал результат в 1.6–2.2 раза (`PIT-H`, счётчик 3).
- **Не верить числам без зелёной канарейки** — агент обязан прогнать `--selftest` первым.
- **Не выдавать `/context` за замер.** Он показывает **текущее** состояние, лог —
  всю историю с ценой каждого хода.

## Быстрый ручной путь, если агент недоступен

```bash
python3 reports/experiments/token-consumption/session_metrics.py --selftest   # канарейка
python3 reports/experiments/token-consumption/session_metrics.py              # срез
```

Скрипт сам находит лог текущей сессии и печатает готовую строку CSV.
