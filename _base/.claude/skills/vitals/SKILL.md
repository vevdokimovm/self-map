# `/vitals` — система в порядке или нет, одним ответом

## 🔴 Почему `/vitals`, а не `/status`

Скилла называлась `/status` один день и была переименована 29.08.2026:
**у Claude Code есть встроенная `/status`** («показать статус текущей
сессии»), и наша её перекрыла — встроенная команда стала недоступна.

Имя выбрано не наугад: **жизненные показатели** — это ровно то, что скилла
печатает. Семь порогов, каждый как отдельный показатель, и медицинская линия
в системе уже есть — триаж START с чёрной меткой, усталость от тревог,
пороги вместо потока.

> **Урок шире имени:** свой скилл, названный как встроенная команда, **молча
> отбирает её**. Проверять занятость имени надо ДО заведения, а не после.

## Зачем эта скилла существует

Вопрос «всё ли в порядке» раньше требовал пяти команд и чтения их вывода.
Хуже: **вывод был потоком, а не ответом** — человек читал сорок строк и сам
решал, есть ли повод вмешаться.

🔴 **Уведомление, которое всё равно надо прочитать и осмыслить, контроль
не снижает.** Оно меняет активное решение на пассивный надзор, а пассивный
надзор человек выполняет хуже: Mackworth (1948) — падение точности
обнаружения на **10–15 % за первые полчаса**. Дальше вступает усталость
от тревог: в медицине **72–99 % клинических тревог ложные**.

Поэтому здесь порог, а не поток: **зелёное молчит**.

## Что делать

**1. Уровневый смотритель — главный ответ:**

```bash
python3 ~/repos/base-repo/scripts/system_status.py
```

Он опрашивает семь порогов по состоянию диска, ничего не помня с прошлого
раза. Перешедшие порог — печатает, остальные молчат.

**2. Если смотритель красен по «отставших от канона»** — это чинится одной
командой, и её можно выполнить сразу:

```bash
python3 ~/repos/base-repo/scripts/sync_base_local.py --all
```

**3. Если красен по «просроченным задачам»** — это действия владельца.
🔴 **Исход за него не выбирать.** Показать список и назвать три законных
исхода: перенести с новой датой · в раздел «⚫ НЕ ДЕЛАЕМ» с причиной ·
вычеркнуть.

**4. Планировщик сверяется отдельно** — он про содержание, а не про диск:

```bash
python3 ~/repos/base-repo/scripts/planner_audit.py
```

**5. Только если владелец просит подробностей** — прогон гейта по репам.
Не по умолчанию: он идёт минуты и печатает много.

## Чего эта скилла НЕ делает

- **не чинит найденное молча** — половина расхождений требует необратимых
  действий, а они стоп-класс авто-режима;
- **не заменяет гейт**: гейт судит ОДНУ репу по правилам, смотритель судит
  СИСТЕМУ по целевому состоянию;
- 🔴 **не знает о том, чего нет в файлах.** Дыра, про которую никто
  не написал, невидима и здесь. Уровневость снимает потерю события,
  но не отсутствие знания — это надо сказать вслух, если владелец
  спрашивает «точно всё?».

## Как отвечать

Одной короткой сводкой, а не выводом команд целиком. Всё зелёное — так
и сказать: «ни один порог не перейдён», и назвать, **что именно
проверялось** — иначе «всё в порядке» ничем не отличается от «не смотрел».
