- **Василий:** Bron–Kerbosch algorithm
- **Василий:** Алгоритм Брона – Кербоша предназначен для поиска всех максимальных кликов в неориентированном графе.
  
  Клика — это множество вершин, каждая пара которых соединена ребром.
  Максимальная клика — клика, которую нельзя расширить, добавив в неё какую-либо другую вершину графа.
  Работает он рекурсивно, поддерживая три множества:
  
  R — текущая растущая клика,
  P — кандидаты, которые ещё могут быть добавлены в R,
  X — вершины, которые уже были рассмотрены и не должны повторяться.
  На каждом шаге алгоритм:
  
  Если одновременно P и X пусты, то R — это максимальная клика, и она выводится.
  Иначе выбирается опорная вершина u из P∪X (оптимизирующий приём),
  Формируется множество кандидатов C = P \ N(u) (только те кандидаты, которые не соседствуют с u),
  Для каждой вершины v из C:
  R₁ = R ∪ {v}
  P₁ = P ∩ N(v); X₁ = X ∩ N(v)
  рекурсивно вызывается BronKerbosch(R₁, P₁, X₁)
  из P удаляют v, а в X добавляют v (чтобы не повтарять клики).
  Благодаря точному разделению кандидатов и исключённых вершин и использованию «опорного» выбора u, алгоритм эффективно перебирает только те ветви поиска, которые действительно могут привести к новым максимальным кликам, и не порождает дубли.

- **Василий:** SDA и SCL — это «дорожки» для разговора по I²C
  У устройств типа дисплея LCD2004 или датчика BME280 есть шина I²C. Она состоит всего из двух проводов:
  SDA (Serial Data) — по нему идут данные (буквы, цифры, команды).
  SCL (Serial Clock) — это тактовый сигнал, он задаёт ритм: «тик-тик-тик». Под эти «тики» устройство понимает, когда считывать очередной бит данных с SDA.
  Пример из жизни
  Представь, ты диктуешь другу цифры, а он записывает:
  SDA — твои слова (данные).
  SCL — ты хлопаешь в ладоши (такты). На каждый хлопок друг понимает: «Окей, сейчас надо записать одно число».
  Без хлопков (SCL) твой друг не понял бы, где начало и конец цифры.
  Зачем это на Arduino
  Arduino (master) соединяется с устройством (slave) всего через два провода.
  SDA передаёт команды («выведи 24.0 °C»).
  SCL задаёт ритм, чтобы команды читались синхронно.
  Почему именно так удобно
  Не нужно десяток проводов — все устройства сидят на одной SDA и одной SCL.
  У каждого устройства есть свой адрес (как номер квартиры). Arduino говорит: «Эй, устройство №0x27, выведи текст!», и только этот дисплей реагирует.
  👉 То есть SDA = сами данные, SCL = метроном, который задаёт темп чтения этих данных.

  ✅ cat input.txt | python3 mapper.py | sort | python3 reducer.py
  (сначала map, потом sort по ключам, потом reduce)
  4️⃣ Что происходит на стадии shuffle в MapReduce?
  ✅ Данные сортируются по ключам перед передачей Reducer-ам
  ✅ Mapper-ы передают промежуточные данные Reducer-ам по ключу
  5️⃣ Какую роль выполняет Application Master в YARN?
  ✅ Управляет выполнением одного конкретного приложения и его контейнерами
  6️⃣ Какие основные задачи выполняет Resource Manager в архитектуре Yarn?
  ✅ Управляет распределением вычислительных ресурсов между приложениями
  ✅ Следит за состоянием узлов и планирует запуск контейнеров
