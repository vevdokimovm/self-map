# СТАНДАРТ: визуальное описание + промежуточные отчёты
**Дата:** 15.07.2026. Обязателен для ВСЕХ картиночных источников (Инста, VK, дневник, Приятное, брат). Читать с `00-protocol/02-process.md`.

## A. ВИЗУАЛЬНОЕ ОПИСАНИЕ — МАКСИМАЛЬНО ПОДРОБНО (текст ЗАМЕНЯЕТ картинку)
**Цель:** по описанию можно восстановить смысл кадра, не видя его. Если можно подробнее — делать подробнее.
На КАЖДЫЙ кадр/пост фиксировать:
- **Субъект:** кто/что в кадре (Василий / друзья / объект), сколько людей.
- **Поза / действие:** положение тела, жест, что делает, направление движения.
- **Лицо / эмоция:** выражение, глаза (открыты/закрыты, куда смотрят), считываемое настроение.
- **Одежда / вид:** что надето, стиль, детали, маска/аксессуары, причёска.
- **Обстановка / локация:** интерьер/улица/природа, детали фона, предметы, место.
- **Свет / цвет:** ч/б или цвет, тип освещения, источник света, тональность.
- **Композиция / техника:** план (крупный/средний/общий), ракурс, эффекты (blur, длинная выдержка), кадрирование.
- **Настроение / эстетика:** общее впечатление, отсылки (напр. Rumbling/AoT, нуар, гранж).
- **Текст НА кадре:** любые надписи/стикеры/теги внутри изображения.
- **Карусель/видео:** описывать каждый ВИДИМЫЙ кадр; для видео — стоп-кадр + тип (рилс).
- Нечитаемо → `[КАДР НЕ ПРОСМОТРЕН — причина]`, ретрай, занести в лог пробелов. **НЕ выдумывать.**
> Эталон детальности — Пост 1 в `02-notes/instagram.md` (ВИЗУАЛЬНЫЙ СЛОЙ).

## B. СЛОИ ПО ВИЗУАЛУ (те же, что для текста)
- **0b intelligence по визуалу:** повторяющиеся мотивы (маски, ч/б, blur, локации, позы), эволюция стиля во времени, визуальные «серии», флаги значимых кадров.
- **0c cross-file:** связывать визуальные мотивы с текстом/дневником/снами/тестами; гипотезы (напр. «эстетика распада ↔ тёмные периоды») — в `01-registry/facts-and-hypotheses.md` со статусом.

## C. ПРОМЕЖУТОЧНЫЙ ОТЧЁТ — что ОБЯЗАН содержать каждый батч
1. **Что сделано:** какие стр./посты, ОБА канала (текст + визуал).
2. **Охват:** X/Y стр.; кадров просмотрено / не просмотрено.
3. **Находки:** ключевое (intelligence / cross-file / гипотезы).
4. **⚠️ ПРОБЛЕМЫ:** что пошло не так, что затруднило, где риск халтуры.
5. **ДОПУЩЕНИЯ:** любые сделанные предположения (чтобы ошибочные было видно сразу).
6. **ЛОГ ПРОБЕЛОВ:** какие стр./кадры не сняты + причина + **как это чинить**.
7. **Осталось:** что впереди.
> Правило прозрачности: **если начал халтурить/срезать угол — это должно быть ВИДНО из отчёта.** Скрытый недобор = брак.
