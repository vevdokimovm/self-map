## Как запускать
Новый чат → приложить `prep.py` + архивы → выполнить:
```bash
mkdir -p /home/claude/tessdata && cp /usr/share/tesseract-ocr/5/tessdata/{eng,osd}.traineddata /home/claude/tessdata/
cd /home/claude/tessdata && wget -q https://raw.githubusercontent.com/tesseract-ocr/tessdata_fast/main/rus.traineddata
cp /mnt/user-data/uploads/prep.py /home/claude/ && cd /home/claude
python3 prep.py dima 1 1 --no-ocr && python3 prep.py priyatnoe2 1 1 --no-ocr && python3 prep.py diary 1 2 --no-ocr && python3 prep.py priyatnoe 13 13 --no-ocr && python3 prep.py instagram 1 1 --no-ocr && python3 prep.py vk 1 1 --no-ocr
```
Потом смотреть по одной и отвечать на вопрос: **«читаю ли я тут каждое слово уверенно, или додумываю?»**

## ЭКСП-1 🔴 КРИТИЧЕСКИЙ — Дима-ментор ч.1 читается вообще?
**Проблема:** все 55 страниц лежат в **1240×775**. Это максимум, который есть в файле (проверено `pdfimages -list`). Текст сообщений Telegram Web при такой ширине ≈10 px. OCR даже при увеличении ×3 достаёт только обрывки: `September 6, 2020`, `Работа`, `November 19, 2020`.
**Файл:** `/home/claude/READY/dima/p001.png`
**Критерий провала:** если хоть одно сообщение приходится угадывать → ч.1 **НЕЛЬЗЯ читать**, это будет фабрикация цитат.
**Если провал → решение:** Василий переэкспортирует переписку. Лучший вариант — **Telegram Desktop → Настройки → Продвинутые → Экспорт данных → выбрать чат → формат JSON или HTML.** Это даёт идеальный текст, ноль картинок, ноль потерь. Полностью снимает проблему.
**Важно:** ч.2 (61 стр.) — **2560×1600, читается прекрасно** (OCR берёт 92–128 слов/стр). Проблема только в ч.1.

## 💡 ГЛАВНАЯ РЕКОМЕНДАЦИЯ (может сэкономить 5+ чатов)
**Три источника — это Telegram: Приятное (89), Приятное 2 (73), Дима-ментор (116). Итого 278 страниц скринов.**
Если выгрузить их через **Telegram Desktop → Экспорт данных (JSON/HTML)** — получится чистый текст со всеми датами, авторами и вложениями. Это:
- снимает проблему нечитаемости (ЭКСП-1, ЭКСП-2) полностью;
- превращает 278 страниц визуальной работы (≈4–5 чатов) в текст, который читается за 1 чат;
- **ничего не теряет** — наоборот, даёт то, что на скринах обрезано.

**Аналогично:** VK имеет официальную выгрузку данных (Настройки → Защита → Скачать архив), Instagram тоже (Download Your Information). Это ещё 797 страниц → ~12 чатов экономии.

**Скрины при этом всё равно остаются нужны** для медиа (фото, голосовые, реакции) — но их можно смотреть точечно, а не читать текст глазами по страницам.

**Решение за Василием.** Если выгрузок нет или не хочется — работаем как есть, в режиме A.
