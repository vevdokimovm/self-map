## 🎯 Как уточнять (протокол измерения → бинарный поиск)

**Самый точный способ — Claude Code** (показывает и токены, и % лимита в статус-строке):
1. Начни свежую сессию, сделай задачу, прочитай: «использовано N токенов» и «сессия X%».
2. `токенов_на_1% = N / X` → `Сессия = токенов_на_1% × 100`.
3. Аналогично для недельного бара.
Один такой замер **сразу заменяет всю оценку выше точным числом** для твоего аккаунта.

**В вебе/приложении** (только %): косвенно — повторяемая задача известного размера, замеряешь Δ% . Грубее, но работает.

**Бинарный поиск:** держим текущую оценку → каждый замер двигает константу `токенов_на_1%` вверх/вниз → диапазон сужается. 2–3 замера дадут ±10%.

**Что записывать (лог ниже):** дата, модель, что делал, ~токенов (если Code — точно; если веб — оценка), Δ% сессии, Δ% недели. Из накопленного пересчитываем таблицу.
