# 02 — Работа с Claude (инфраструктура базы знаний)

> В этих репах Claude — не помощник сбоку, а **вся инфраструктура**: он читает,
> сжимает, ищет дубли, поддерживает актуальность. Значит, с ним надо работать по
> правилам — как с инфраструктурой. Этот файл: где работать, сколько влезает,
> какую модель брать. Факты о продукте меняются — числа сверять по докам (ссылки внизу).

## 1. Где работать — поверхности Claude

| Поверхность | Для чего | Для базы знаний |
|---|---|---|
| **Проект** | Персистентная knowledge-база + инструкции + набор чатов | **Главный дом репы.** Грузишь материалы один раз, дёргаешь из любого чата |
| Обычный чат | Разовый разговор, файлы живут только в нём | Быстрый вопрос, разбор одного файла вне проекта |
| Cowork (desktop) | Автономная многошаговая не-кодовая работа: разбор, длинные тексты, много файлов | Массовая ревизия репы, сжатие пачки файлов, сверка на дубли |
| Приложения | Claude в Chrome / Word / Excel | Точечно: выгрузка, оформление документа |

Для knowledge-репы рабочая связка: **Проект как дом** (материалы + эти инструкции
в knowledge) + **Cowork** для тяжёлых ревизий.

## 2. Лимиты файлов и почему это диктует формат

| Где | На файл | Число файлов | Важное |
|---|---|---|---|
| Чат | 30 МБ | до 20 на разговор | Всё уходит в контекст (≈200K токенов) — легко переполнить |
| **Проект** | 30 МБ | практически без лимита | 200K = **мягкий потолок**: при переполнении включается **RAG** — Claude тянет только релевантные куски, а не всю репу разом. Контент проекта **кэшируется** и не жрёт лимиты при переиспользовании |

Форматы: PDF, DOCX, TXT, **MD**, CSV, HTML, RTF, EPUB, JSON, XLSX. PDF читается
визуально при <100 страниц.

**Отсюда главный вывод (весь смысл сжатия в `.md`):**
- Пока репа влезает в 200K — Claude видит её **целиком**, точность выше.
- Переросла — уходит в **RAG-выборку**, видит только куски, теряет общую картину.
- Лёгкие тезисные `.md` дольше держат режим «вижу всё». Тяжёлые исходники и дубли
  приближают RAG и портят выборку.
- Протокол сжатия — `06-volume-compression.md`.

## 3. Какую модель брать (две ручки: модель и effort)

Модель решает «кто думает», effort (глубина рассуждения) — «сколько думает». Это
независимые ручки.

| Задача по репе | Модель · effort |
|---|---|
| Сжать файл в тезисный `.md`, переписать раздел, разобрать источник | Sonnet · medium (рабочий дефолт) |
| Крупная реорганизация репы, спорная логика, тонкая сверка на дубли/противоречия | Opus · high |
| Механика: переименовать, поправить ссылки, обновить журнал | Haiku · low |

Дефолт для ведения баз — **Sonnet**; Opus подключай на реально сложное и
ответственное, Haiku — на мелочь. Модель переключается пикером в интерфейсе (это
твоя ручка), Claude её не крутит — но на старте задачи может подсказать пару.

## 4. Дисциплина

- **Актуальный лайнап** моделей узнавай у Claude в моменте — системный контекст
  тоже иногда отстаёт от свежего релиза, при сомнении сверься по докам.
- **Цены и лимиты** — никогда по памяти, только по ссылке (меняются).
- **Закрытую тему — в новый чат.** Гигантская сессия дорожает с каждым ответом
  (перечитывается вся история) и быстрее упирается в лимиты.
