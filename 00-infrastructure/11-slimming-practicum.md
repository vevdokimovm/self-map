# 11 — Практикум: сжатие репы и превращение архива в рабочий инструмент

> Как провести **кампанию по всей репе**: не только срезать вес, но превратить сырой
> архив файлов в **рабочий инструмент-конспект** — со структурой, единым неймингом,
> живыми README и журналом. Порядок фаз, решающие правила «если → то», готовые сниппеты
> и грабли. Основан на боевом прогоне `academic-portfolio`: **236 МБ репы + 2.7 ГБ
> входящих архивов → 42 МБ рабочей копии (~30 МБ на GitHub)** без потери единого
> deliverable, 953 переименования, ноль битых ссылок. Отличие от
> `06-volume-compression.md`: там — как сжать **один файл**, здесь — вся кампания.
> Подробный разбор кейса — `12-case-academic-portfolio.md`.

## Две цели кампании

| Цель | Что означает | Чем меряется |
|---|---|---|
| **Вес** | Репа влазит в порог (🟢/🟡/🔴 из `WATCHLOG.md` §5) и в контекст Claude | МБ; `du -sh` |
| **Инструмент** | Архив → конспект: роутинг по разделам, единый нейминг, README, рабочие ссылки, журнал | чек-лист приёмки внизу |

Вес без структуры — просто маленькая свалка. Структура без веса — красивая, но не влазит.
Делаются обе цели за одну кампанию, фазы ниже покрывают обе.

## Порядок фаз (строго по очереди)

**Блок А — вес (фазы 1–8):**

1. **Бэкап + журнал.** Git-тег `slim-backup` (или копия архива). Открыть `WATCHLOG.md`,
   писать **по ходу** (`04-watchlog-protocol.md`) — токены/сессия кончаются внезапно.
2. **Инвентаризация.** Размеры по папкам (`du`), топ тяжёлых, счётчики расширений.
   Решения — по цифрам, не по ощущениям.
3. **Механика без потерь.** Мусор (`.DS_Store`, `__MACOSX`, `.ipynb_checkpoints`,
   `__pycache__`), дубли по sha256, пары `docx+pdf` одного документа (оставить PDF
   ≤5 МБ), очистка outputs у `.ipynb`.
4. **Датасеты → заметки.** Колонки, объём, источник, как получить — в
   `dataset-notes.md`, файлы удалить. Исключение — мелкие данные, которые читает код.
5. **docx/pptx → `.md`.** python-docx / python-pptx, правило конспекта — `06`.
   Оригинал удалить (хранится локально у владельца).
6. **PDF-роутинг** — каждому PDF один из четырёх маршрутов (таблица «если → то»).
7. **Картинки.** Скан-страницы → в опись; нужные — сжать до ≤0.5 МБ
   (Pillow: resize 1600px + quality 80 / palette PNG).
8. **Остаточные тяжёлые PDF** (deliverables) → Ghostscript `/ebook`: ×2 легче без
   видимой потери.

**Блок Б — инструмент (фазы 9–13):**

9. **Роутинг по разделам.** Разнести свалки (`misc/`, «Разное») по смысловым разделам —
   предмет/тему определять **по содержимому**, не по имени (правило «своё в своей
   зоне», `05` §2.5). Чужое — в свою репу.
10. **Нейминг-ревизия.** Англ. kebab-case по `01-repo-standard.md` — рецепт движка ниже.
11. **Починка ссылок.** По логу переименований одним проходом — рецепт ниже.
12. **README-регенерация.** Разделные README собирать **из файловой системы**
    (списки материалов), а не править руками; исторические таблицы (описи сканов)
    переносить из старых README. Корневой README: карта разделов, highlights новыми путями.
13. **Инфраструктура + приёмка.** Кит `base-repo` (`00-infrastructure/` + `templates/`,
    `.gitignore` по шаблону, WATCHLOG по `03`), журнал §0/§3/§4 в актуальном виде,
    финальный чек-лист → коммит/пуш.

## Решающие правила «если → то»

| Ситуация | Правило |
|---|---|
| PDF с текстовым слоем, извлечено ≤200 КБ | Своя работа → полный текст в `.md` |
| PDF с текстовым слоем, извлечено >200 КБ | **Чужой учебник** → заметка-стаб (автор, название, стр.) |
| PDF-скан (pdftotext < 300 символов) | Опись: тема, источник, страниц. **Не транскрибировать** |
| Скан с OCR-слоем-мусором (`f/1-J :: A(i)J/t)`) | Это скан, не текст → опись |
| Deliverable (диплом, статья, подписанный акт) | **Неприкосновенен**: не конвертировать, не удалять; можно сжать gs |
| Два файла с одним sha256 | Удалить копию |
| `docx`+`pdf` одного документа рядом | PDF ≤5 МБ оставить, docx удалить; PDF >5 МБ — конспект и удалить оба |
| Датасет, который читает код | Оставить если мал; при переименовании чинить пути в коде |
| Файл не по теме раздела/репы | Переместить по смыслу содержимого («своё в своей зоне») |
| Непонятное имя (`аааа.md`, «Разное») | Открыть, определить по содержимому, дать смысловое имя и место |
| Порог PDF | ≤5 МБ и только первоисточники · Картинки: ≤0.5 МБ и только необходимые |

## Нейминг-ревизия: как переварить сотни имён

Порядок разрешения имени (первое совпадение выигрывает):

1. **KEEP-список** — канонические имена не трогаем: `README.md`, `WATCHLOG.md`,
   `LICENSE`, `Dockerfile`, `Procfile`, шаблоны кита.
2. **Точный словарь** — deliverables и все «особенные» файлы/папки поимённо
   (`ВКР_… .pdf → bachelor-thesis-… .pdf`). Сюда же — смысловые переводы предметов.
3. **Паттерны семейств** — regex для массовых серий: `ЛР(\d+)…`, `Лаба(\d+).sql`,
   датированные лекции/семинары (`06.09.23 #1` → `lecture-01-2023-09-06`), `N.JPG` →
   зеро-пад. Один паттерн закрывает десятки файлов.
4. **Механика для латиницы** — lowercase, `_`/пробелы/точки в стеме → `-`, срезать
   скобки/кавычки/апострофы, схлопнуть дефисы.
5. **Транслит-фоллбэк для кириллицы** — пословный словарь (~60 частых слов:
   лекция→lecture, билеты→tickets…) + ГОСТ-транслит для фамилий; **всё, что ушло в
   фоллбэк — печатать в отчёт** и просматривать глазами.

Технические обязательные детали: **NFC-нормализация и ключей словаря, и имён с диска**;
политика кода — `.py/.cpp/.pas` переименовывать **только** при не-ASCII и в snake_case
(kebab ломает импортируемость Python); коллизии в одной папке — суффикс `-2`;
файлы переименовывать раньше папок, папки — снизу вверх; **каждое переименование —
в JSON-лог** `старое → новое` (без него фаза 11 невозможна).

## Починка ссылок после переименований

- Имена **файлов** (с расширением — они уникальны) — прямой replace по всему тексту
  `.md`/`.py`/`.sql`/`.cpp`/`.html`.
- Имена **папок** — только в path-контексте: `старое/` → `новое/` и `](старое)` →
  `](новое)`, иначе заденешь прозу («Материалы» в тексте ≠ путь).
- `.ipynb` — **только через `json`**: кириллица там бывает в `\u`-эскейпах, текстовый
  replace промахивается.
- Упоминания удалённых оригиналов (`Извлечено из «X.pptx»`) — не трогать, это история.
- После: линк-чекер по всем `.md` (relative → `os.path.exists`); битые ссылки на
  картинки из бывших docx → нейтрализовать в «*(рис. из оригинала — не сохранён)*».

## Ядра-сниппеты (проверены в бою)

**Распаковка macOS-zip (кириллица):**
```python
name = info.filename
if not (info.flag_bits & 0x800):            # UTF-8 флага нет → zipfile декодит CP437
    name = name.encode('cp437').decode('utf-8')
name = unicodedata.normalize('NFC', name)   # macOS отдаёт NFD
```

**Классификатор PDF (текст или скан):**
```python
txt = subprocess.run(['pdftotext', p, '-'], capture_output=True, text=True).stdout
is_text = len((txt or '').strip()) > 300    # меньше — скан, в опись
```

**Очистка ipynb:**
```python
nb = json.load(open(p))
for c in nb['cells']:
    if c['cell_type'] == 'code':
        c['outputs'], c['execution_count'] = [], None
json.dump(nb, open(p, 'w'), ensure_ascii=False)
```

**Сжатие PDF (Ghostscript, замена только если стало меньше):**
```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/ebook \
   -dNOPAUSE -dQUIET -dBATCH -sOutputFile=out.pdf in.pdf
```

**Дедуп по содержимому:**
```python
h = hashlib.sha256(open(p,'rb').read()).hexdigest()   # видел хэш → удаляй копию
```

**Починка mojibake после pdftotext (кириллица как latin-1):**
```python
fixed = broken_text.encode('latin-1', errors='ignore').decode('cp1251', errors='ignore')
```

## Грабли (не переоткрывать)

1. **macOS-zip без UTF-8 флага** → имена `╨╡╤ü…`, роутинг разваливается. Контент цел.
   Фикс — сниппет выше.
2. **NFC vs NFD.** macOS отдаёт NFD («й» = «и»+бреве); словари в NFC молча
   промахиваются — **нормализуй и ключи, и диск**. После массовых переименований —
   контрольный скан `unicodedata.combining()`.
3. **Консоль врёт про кодировку.** Кракозябры в выводе ≠ битые файлы. Проверяй
   кодпойнты, не глазами.
4. **Дампы чужих учебников** маскируются под «извлечённый текст». Порог 200 КБ —
   надёжный детектор.
5. **OCR-слой рукописи — мусор**, но проходит проверку «текст есть». Нечитаемо → скан → опись.
6. **Переименование ломает ссылки** — в README, конспектах и коде (пути к данным!).
   Лог `старое → новое` обязателен, чинить одним проходом.
7. **Битые img-ссылки из docx** портят рендер на GitHub → нейтрализовать в пометку.
8. **Сначала манифест, потом удаление** — опись снимается **до** `os.remove`.
9. **Диск конечен** — гигабайтные архивы по одному: распаковал → отжал → удалил → следующий.
10. **Токены кончаются внезапно** — журнал по ходу, тяжёлое коммитить частями (`04` §5).
11. **Правки журнала — по заголовкам секций**, не многострочным regex: секции меняются,
    хрупкий regex молча не совпадает и правка теряется. `split('## §3')` надёжнее.
12. **Не гонись за цифрой в интерфейсе GitHub** — он показывает сжатые объекты
    (наши 42 МБ рабочей копии = ~30 МБ на GitHub). Меряй `du -sh` рабочей копии.
