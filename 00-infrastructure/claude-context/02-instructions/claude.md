## Code Style Rules (always, без напоминания)

| Rule | Preference |
|------|-----------|

| Naming | Strict PEP 8 (snake_case vars, PascalCase classes) |

| Secrets | Через `.env`, никогда не хардкод |
| Python version | Python 3 only, никогда Python 2 |
| Global variables | Избегать |
