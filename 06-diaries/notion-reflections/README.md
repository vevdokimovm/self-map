# Notion Reflections Diary

Personal reflection diary exported from Notion (2020–...). Already processed into a clean dataset.

| Path | Content |
|---|---|
| `entries/` | 321 diary entries as dated Markdown files (`YYYY-MM-DD.md`). |
| `datasets/` | Combined CSV datasets built from the entries (`diary-combined.csv` is the main one). |
| `scripts/` | Python scripts used for cleaning/merging the export. |
| `source/` | Raw Notion database CSVs (hash suffixes stripped). |

> Media attachments from the export (~438 MB of photos/videos in dated folders) are intentionally **not** in the repo — store them in the photo archive / cloud, not in a knowledge base.
